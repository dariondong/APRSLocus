# APRSlocus

**APRS 定位追踪与地图** — 专为业余无线电爱好者打造的 APRS 客户端

> 作者：BG7LZQ (Darion) · 网站：[Theez.top](https://theez.top)

APRSlocus 是一个轻量、易用的 APRS（Automatic Packet Reporting System，自动分组报告系统）客户端，基于 Flutter 开发，支持 Android 与 Windows。它将实时定位、台站追踪、消息收发与地图显示融为一体，让您随时随地掌握电波世界的一举一动。

---

## ✨ 核心功能

### 🗺️ 实时地图追踪
- 高德地图瓦片（GCJ-02），流畅缩放拖拽
- 实时显示所有台站位置，状态一目了然
- 在线 / 停止 / 离线三色标识，活跃台站脉冲动画

### 📡 位置信标
- 一键上报位置，支持自定义信标内容
- 完整 APRS 标准格式，兼容主流 APRS 软件
- 自动附带高度、速度、航向、电量信息

### 💬 消息通信
- 瀑布流 + 会话双模式，像聊天一样收发
- 支持中文消息与自动应答
- 群发、搜索、历史记录自动保存

### 🚒 台站识别
- 自动识别 FMO（机动消防）台站
- 同款 APRSlocus 软件台站自动标记，显示版本 / 电量 / 高度
- 支持 37 个官方符号表，3571 个标准图标

### 🛠️ 丰富功能
- APRS-IS 公共服务器自动连接，后台保持在线
- 图层筛选（移动 / 固定 / 中继 / 气象 / FMO）
- 原始数据包查看与检索
- 首次使用引导，上手零门槛

## 📥 下载安装

### Android
- 下载 `APRSlocus-release.apk`，允许「未知来源」后安装
- 最低支持 Android 5.0

### Windows
- 下载 `aprslocus.exe`，双击即用，无需安装

## 🚀 快速上手

1. 打开应用，输入您的业余无线电**呼号**（如 `BG7LZQ-3`）
2. 密码填 `-1` 即可，或到 [aprs2.net](https://aprs2.net) 生成
3. 选择一个代表台站类型的**符号**
4. 完成引导，自动连接 APRS-IS 并开始上报位置

详细教程见下方使用指南。

---

## 📖 使用指南

- [完整使用教程](./README.md) — 面向用户的逐步说明
- 新手建议先使用**演示模式**熟悉界面
- 移动端 SSID 建议使用 `3`，手持台用 `7`

### 信标示例

APRSlocus 发送的位置信标遵循 APRS 1.0 标准：

```
BG7LZQ-3>APALOC,TCPIP*:!2148.90N/11049.14E/> /A=000328 090/050 Bat:70% APRSlocus v1.2.5
```

### 符号说明

| 符号 | 含义 | 符号 | 含义 |
|------|------|------|------|
| `>` | 汽车 | `-` | 房屋 |
| `[` | 人 | `k` | 卡车 |
| `b` | 自行车 | `W` | 气象站 |
