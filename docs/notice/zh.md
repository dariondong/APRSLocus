# ⚠️ 重要公告 · 2.0.3 已撤回，建议回退至 2.0.2

**2.0.3 属非正常发行：它由一次在正常发版流程之外提升版本号的变更带出。我们已把该版本从 Release 与官网撤回，建议仍在使用 2.0.3 的朋友回退到 2.0.2。**

---

## 一、发生了什么

**v2.0.3 已经撤回。**

它源于一次**不合规的版本号变更** —— 在正式发版流程之外，项目版本号被从 **2.0.2** 提升为 **2.0.3**，并据此生成了发行版。

这违反了本项目的一条硬性规则：**版本号只能由维护者在正式发版时统一提升**，任何功能贡献都不应改动它。因此 v2.0.3 属于**非正常发行**，我们已完成以下处理：

- 删除 GitHub 上的 v2.0.3 **Release** 及其**标签**；
- 把官网与下载入口**回退到 2.0.2**；
- 将相关改动从主分支**整体回滚**。

---

## 二、建议：回退到 2.0.2

如果你已经安装或正在使用 2.0.3，**建议回退到 2.0.2**。

- **Android**：下载并安装 **APRSLocus_2.0.2.apk**；若提示签名冲突无法覆盖安装，请先**备份**（呼号、台站备注、自定义主题等重要设置），再卸载 2.0.3 后重新安装。
- **Windows**：下载并运行 **APRSLocus_Setup_2.0.2.exe**。
- **iOS**：下载 **APRSLocus_2.0.2_unsigned.ipa** 自行签名安装。

[▶ 前往下载 2.0.2](https://github.com/dariondong/APRSLocus/releases/tag/v2.0.2)

> 建议回退前先做一次备份（设置 → 备份与恢复），换机与降级都用得上。

---

## 三、为什么版本号这么重要

APRSLocus 会把版本号**发送到空中** —— 在 APRS-IS 与射频的身份帧 / 在线帧里都带着它（形如 APRSlocus CONNECT v2.0.2）。

如果出现两个都自称 **2.0.3** 的安装包，在 aprs.fi 这类平台上就**无法分辨**到底是哪一个在发信标：出了问题也没法定位。版本号是这个项目在电波里的身份，必须保持唯一，且只能由维护者在正式发版时提升。

---
