# 📦 2.0.13 · APRSlocusBOX —— 用手机管你那台小盒子

**2.0.13 已发布。** 这一版把「小盒子」（ESP32 + 屏 + 旋钮那台）接进了应用：
「设备」页多了一条 **APRSlocusBOX** —— 连上之后，手机上就能读它的配置、改它的配置、
把手机的位置喂给它、催它发一帧信标、看它到底在干什么。

**先说结论：没有盒子的人什么都不用做。** 这一版不需要你做任何设置，升级方式也没变。

---

## 一、盒子推回来、手机上看得见

连上盒子之后，应用能看到它**自己报回来的**东西：

- 呼号 / SSID、链路模式（wifi / bt / both）、自动信标间隔、APRS-IS 服务器、GPS 波特率；
- 发出去多少帧（TX）、发了多少次信标（BEACON）、收到多少条消息（RXMSG）、
  确认了几条（ACK）、错了几次（ERR），以及**最近一条事件原文**；
- 盒子推回来的 `EVT …` 事件与命令回执，全部进日志，可一键复制 ——
  出问题时这就是唯一的证据。

## 二、手机也能替盒子做点事

- **改配置**：全部 23 个键都在（键名与盒子文档逐字一致），点一项就地改。
  改完应用会**自动回读** —— 所以屏幕上显示的是**盒子里的真值**，不是你刚输入的值；
- **喂位置**：把手机当前的坐标喂给盒子（`POS lat lon [alt] [spd] [crs]`），
  也可以开「自动喂位置」（30 秒一次）。盒子没装 GPS 的时候，出门带手机就能用；
- **催它动作**：立即信标 / 状态报文 / 重连 APRS-IS / 清空台站 / 格式自检 / **重启盒子**
  （链路模式与蓝牙这类"开机设置"改完要重启才生效，现在不用拔电了）。

## 三、新：手机状态给盒子（盒子的 PHONE 页）

这一版还把**手机这侧看到的东西**推给盒子：自己的速度、方位、海拔、有没有定位、
APRS-IS 通不通、未读消息，以及**附近台站列表**（按距离排，最多 8 条）。

盒子那边新增了一页 **PHONE** 显示这些，首页底行也会写一句 `PH 12km/h`；
页头有个 `P` 标记 —— **亮着**才说明手机正在推（120 秒没推就变暗，不拿旧数据骗人）。

为什么需要它：盒子只跑蓝牙时**自己不上 APRS-IS**，「旁边有谁」在它上面本来是空的；
就算在 wifi 模式，手机的过滤半径与位置也未必与盒子相同 —— 两边对照着看才有意义。

## 四、两条刻意的规矩

- **盒子不是「数据来源」**：它自己就上 APRS-IS、自己组报文，本应用再收一遍只会重复。
  所以它只作为「一台要管的设备」出现在设备页，不进数据来源多选；
- **绝不自动发射**：信标与状态报文必须你自己点（与「射频发射永远要显式」同一条规矩）。
  自动的只有本地的位置喂养与状态推送 —— 它们只写盒子的位置与屏幕，**不上射频**。

## 五、需要烧固件吗

需要。应用这一半（协议 + 界面）在这一版里做完了；**盒子那半是另一份固件工程**，
有盒子的人需要自己烧一次（盒子侧同步新增了 PHONE 页，也做了一次界面重做）。
没有盒子的话，这一版对你没有任何影响。
