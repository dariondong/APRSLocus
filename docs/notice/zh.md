# 📦 2.0.11 · 安卓安装包从 81.6 MB 降到约 30 MB

**2.0.11 已发布。** 这一版**没有加功能**，只做了两件事：**把安卓安装包按 CPU 架构分开打**（体积降到原来的约三分之一），以及**更新页能列出各个包** —— 因为从这一版起，Release 里会有三个安装包。

**先说结论：不知道怎么选就不用管它。** 应用内「检查更新」照旧下载 64 位那个包，和你以前的升级方式完全一样。

---

## 一、为什么以前那么大

以前打的是**通用包**：一个 APK 里塞进**三套 CPU**（arm64-v8a / armeabi-v7a / x86_64）的机器码，而你的手机只会用其中一套，另外两套是**白带的**。

实测 v2.0.10 的包（81.6 MB）里：

- 三套原生库合计 **76.6 MB（94%）** —— 每一套里是两样东西：你的应用代码编译出来的机器码（14~17 MB），以及 Flutter 引擎（8~12 MB）；
- 其余全部加起来只有约 4 MB（图片、图标、符号表、文字等）。

所以「瘦身」的办法不是删功能，而是**别让每个用户都带上三份**。

## 二、现在 Release 里有三个包

每个都约 **30 MB**：

- **`APRSLocus_2.0.11.apk`** —— **64 位**，用于**绝大多数手机**（2015 年以后的机型）。**应用内更新下载的就是它**，升级方式没变。
- **`APRSLocus_2.0.11_armeabi-v7a.apk`** —— **32 位**，用于较老的机型。**只有只支持 32 位的手机才需要它**（这类手机装 64 位包会提示「与设备不兼容」）。
- **`APRSLocus_2.0.11_x86_64.apk`** —— 只用于**模拟器 / Chromebook**，真机一般用不到。

> 不用自己挑：应用内「检查更新」会按你这台手机的 CPU 自动选对应的那个。三个包是同一份代码，只是按 CPU 各编译了一遍。

## 三、更新页会替你挑好，并直接在应用内下载

安卓上「检查更新」页会**按你手机的 CPU 自动挑好对应的包**，**直接在应用内下载**（不跳浏览器），并写明这次下的是哪个包（文件名 · 架构 · 大小）。32 位的老机器会自动拿到 32 位包 —— 不会再出现「下完却提示与设备不兼容」。

需要别的架构（比如给模拟器）可以到 [Releases](https://github.com/dariondong/APRSLocus/releases) 页面自己取。

顺带修掉一处显示问题：以前下载时页面上会**同时出现两条进度条**（看着像两个任务），现在只有一条。
