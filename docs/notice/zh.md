# TOUCH SKY · 感谢公告 · A Thank-You Letter

**APRSLocus 2.0 BETA 开发启程**

从纯网络到射频，从「看见」到「抵达」。

亲爱的 APRSLocus 同行者：

当 **FIRST FIX** 第一次亮起，我们还在网络的深处寻找一枚坐标。屏幕里的光点，穿过云端与服务器，落在地图上，像第一次呼吸。如今，**TOUCH SKY** 让信号离开线缆，进入空气，越过山脊，穿过城市，落在射频的波纹里。从纯网络到射频，不只是技术的迁移，更是从「看见」到「抵达」的旅程。

感谢 APRS 社群、中继站、iGate、服务器维护者、地图与数据提供者，以及所有开源项目与业余无线电前辈。你们是看不见的桥，是沉默的岸，让网络与射频之间有了路，让每一次定位都能抵达更远的地方。

1.0「**FIRST FIX**」让我们站稳，2.0「**TOUCH SKY**」让我们仰望。从纯网络到射频，我们把「已连接」写成「已听见」，把「数据抵达」写成「天空回应」。而现在，我们正式转向 **APRSLocus 2.0 BETA** 开发。TOUCH SKY 不是终点，而是下一段航程的起点。

欢迎测试者、HAM 友与开发者加入 **2.0 BETA**。你的日志、建议、复现与耐心，仍是这条路上最亮的信号。

> FIRST FIX 是起点，TOUCH SKY 是致意。2.0 BETA，是下一次出发。  
> 天空很大，我们继续同行。

> 电波无限，感谢同行！73！  
> APRSLocus 开发团队
