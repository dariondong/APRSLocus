## 🚀 2.0 更新内容（1.5.8 → 2.0，322 次更新）

### 全新 UI 2.0
地图为基底 + 可拖拽面板 + 悬浮胶囊导航；横屏三端重做；磨砂玻璃 / 云母材质。

### 连接与射频
蓝牙 TNC（完整 KISS）、声卡软 TNC（AFSK 1200）、PKWDWPL、iGate；多数据来源可同时收，发射来源单独指定；内置链路自检。

### 消息与翻译
单聊群聊统一会话 + ACK；翻译接口 4 → 7，默认免密钥；双向翻译、对照显示、发送前翻译、语言自动记忆。

### 地图与定位
多图源、沉浸地图、离线地图、历史轨迹回放；去掉聚合；智能信标（按转弯 / 按距离），静止防抖。

### 台站识别
接入 aprs.org 官方设备库，识别厂商 / 型号 / 类别；内置 37 符号表、3571 图标。

### 天气 · 传播 · 小组件
业余无线电建议分级（安全警示 > 注意 > 通联机会 > 操作提示）、短波电离层逐波段日 / 夜条件、Android 三种桌面小组件。

### 个性化与数据
主题自定义 + 背景图 + JSON 分享、备份与恢复、ADIF 导出、统计面板。

### 多语言与设备
6 种界面语言；Garmin LiveTrack、蓝牙心率带。

以及 322 条里数不清的修复。

## ⚠️ 升级前必读

- **v1.4.9 之前的老版本**：因 Android 签名密钥变更，**无法直接覆盖安装**。请先**备份**呼号、台站备注、自定义主题等重要设置，然后**卸载旧版**，再安装新版。
- **v1.4.9 及之后版本**：通常可直接覆盖升级，建议升级前同样做好备份。
