# 📡 2.0.4 已发布 · 此前撤回的功能已正式回归

**2.0.4 已正式发布。** 此前因**版本号在正常发版流程之外被提升**而撤回的那批功能（位置报文数据扩展 `/A=` 高度与 PHG 功率 / 天线高度 / 增益、独立状态报文及其显示），已在**去掉版本号变更**之后按正常流程重新合并，并随本次正式版本发布。

如果你现在还在 2.0.3，请升级到 **2.0.4**（2.0.3 仍属非正常发行，原因见下）。

---

## 一、本次发布包含什么

- **位置报文数据扩展（PHG）**：设置 → 电台 → 台站备注 →「高级设置」可填功率（瓦）/ 天线高度（英尺）/ 增益（dB）。填任一项即附上固定 7 字节的 `PHGphgd`；量化照 APRS101 做（功率只取不超过实际值的最大档 —— 报大了等于虚报覆盖范围），设置页会把真正会发出去的内容回显出来。报文里的位置也照规范：`PHG` **紧跟符号**。
- **高度（`/A=`）**：可手填海拔，**留空则跟随定位**（默认行为不变）。
- **独立状态报文**：可填状态文本，与位置报文共用一个「发射」按钮；留空时发内置的 `APRSlocus CONNECT` 在线帧。收下来的状态报文会显示在台站详情与地图信息窗。
- **若干修正**：发射按钮会先查链路、没有定位时如实说明、状态报文用自己的连接文案、地图页「距下次上报」每秒刷新、设备页「链路自检」不再重复标题、手机电量开关仍在信标页。

完整内容见更新日志。

## 二、关于 2.0.3：仍建议不要使用

**2.0.3 仍属非正常发行。** 它源于一次**在正式发版流程之外把版本号从 2.0.2 提升为 2.0.3** 的变更，并据此生成了发行版。

APRSLocus 会把版本号**发送到空中**（APRS-IS 与射频的身份帧 / 在线帧里都带着它）。如果出现两个都自称 **2.0.3** 的安装包，在 aprs.fi 这类平台上就**无法分辨**到底是哪一个在发信标 —— 出了问题也没法定位。因此该版本已从 Release 与官网撤回。

若你安装过 2.0.3，请**升级到 2.0.4**。

---

## 三、一条规则：版本号只由维护者在发版时提升

功能贡献照常欢迎 —— 提 Issue、报告问题、提交 PR 都可以；需要共同遵守的只有一条：**不要改动版本号**，它只在正式发版时由维护者统一提升。
