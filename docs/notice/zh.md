# 🆘 2.0.9 · 生命守护「碰撞与摔倒检测」测试上线

**2.0.9 已发布。** 这一版把**生命守护**从「心率异常告警」扩到**碰撞与摔倒检测** —— 手机感知到一次强烈冲击、而之后你一直没有动静，它就会弹提醒，并推到系统通知栏。

**这是测试功能，请按「可能有用、也可能误报」来用。** 下面把判据与注意事项一次说清，读完再决定要不要让它一直开着。

---

## 一、它怎么判断「你可能出事了」

两段判据，**两段都满足**才提醒：

**① 冲击** —— 去掉重力之后的加速度瞬时超过 **3.2 g**。车祸与摔倒都会给出这样一个尖峰；急刹这类「持续加速度」不算尖峰（重力已经从读数里分离出去了）。

**② 随后静止** —— 冲击之后连续 **12 秒**几乎没有明显运动。

为什么必须有第二段：只看尖峰的话，**过减速带、手机掉在桌上、甩一甩**全都算，一天响好几次就没人再看了。代价要说明白：**轻微碰撞（人还能动）不会提醒** —— 这个功能管的是「人已经动不了了」，不是「发生过撞击」。

另有两道防抖：应用启动后 **20 秒**内不做判断（刚拿起来、放下也会产生尖峰）；两次提醒之间至少间隔 **3 分钟**（一次事故之后会连续出现多个尖峰）。

## 二、注意事项（请逐条读）

- **它会误报。** 过减速带之后正好等红灯停了 12 秒，就满足两段判据。提醒里第一个按钮就是「我没事」，按掉即可，不影响其它功能。
- **是启发式判断，不是工程级碰撞检测。** 阈值固定、不看行车方向、不融合 GPS、不做任何多方确认。
- **它只提醒，不代替你行动。** 拨打急救电话、向附近台站求助，都必须**你亲手按** —— 应用不会自动拨号，也不会自动发出任何求救。
- **「向附近台站求助」不是 110 / 120。** 它是取 100 公里内最近的 **5 个** APRSLocus 台站各发一条 `SOS CRASH HR=… 坐标`（心率告警时是 `SOS HR=…`），发送前还会再确认一次。对方**不一定在线、不一定看手机**；附近没有已知台站就发不出去（界面会如实提示）。
- **依赖手机硬件与运行状态。** 需要手机有加速度计（没有的话页面上会写明「这台设备检测不了」）；加速度计不需要额外授权。**系统结束应用进程之后不会有提醒** —— 它没有做后台常驻服务。
- **默认开启**，可在**设置 → 生命守护**关闭。它**不需要**你开着定位或发射信标：即使不定位，它也继续守着（这是刻意做的，出门骑行常关定位省电）。
- **请不要把它当作唯一的安全措施。** 骑行、驾驶请照常注意安全；真遇到紧急情况，请直接拨打 **110 / 120**。

## 三、原有的心率告警前提没变

生命守护里原有的**心率异常告警**照旧：需要**外置心率设备已连接、且在正常推数据**（蓝牙心率带或佳明 LiveTrack），读数达到或越过你设的上限 / 下限才弹，**读数过期不报警**。上限、下限与紧急号码都在同一页，改完立即生效。

## 四、这一版还修了三处

- **步数一直显示「请授权」，其实已经授权了。** 读数为 -1 有三种完全不同的原因：没有计步传感器 / 没有活动识别权限 / **还没收到第一个硬件事件**（没有权限时系统只是不派发事件、并不报错）。之前混为一谈，于是「刚授权还没走过路」被显示成「请授权」。现在分成四态：不支持 / 需授权 / **等待数据** / 正常。
- **生命守护页的开关点了没反应**（写回了状态，但页面不跟着刷新）。
- **速度档编辑弹层的「保存」被三大金刚键压住** —— 底部现在同时让出键盘与系统导航栏。
