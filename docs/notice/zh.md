## 这次加了 6 条

1. **3.5 网关转发要自己负责**：把 APRS-IS 收到的报文转到射频发射（网关 / iGate），等于
   **代表他人在业余频段上发射** —— 呼号、频率、功率、工作方式都得合法合规；
2. **3.6 未成年人**：应在监护人同意与指导下使用，由监护人承担后果；尤其不得在没有
   相应资格的情况下进行射频发射；
3. **3.7 发出去的内容**：APRS 是公开、跨国的网络 —— 内容要真实、准确、合法，并尊重
   不同国家和地区的法律、宗教与文化习俗；
4. **5.3 会让哪些第三方看到什么**：查天气会发送位置、翻译消息会发送待翻译文本、检查
   更新会向 GitHub 请求版本、佳明 LiveTrack 会访问你填的链接、地图瓦片来自多个第三方
   —— **不使用这些功能就不会发生**；
5. **7.6 "生命守护"等不是医疗设备**：碰撞 / 摔倒检测、心率告警只是基于手机传感器与
   定位的辅助提醒，可能漏报、误报或延迟，**不是紧急救援服务**；紧急情况请直接拨打
   当地急救电话；
6. **9.4 关于赞赏**：赞赏完全自愿，不换取任何功能、优先支持或服务承诺，且不予退还；
   未成年人请先取得监护人同意。

## 这一版顺手修了什么

- **修好了"蓝牙连不上就闪退"**：那是把阻塞的蓝牙连接放在了主线程上，系统会判定
  "应用无响应"并把它关掉；现在连接在工作线程进行，失败也会如实报错；
- **手机电量不再"半天不动"**：以前只在有定位时才读一次，手机放着不动就会被冻住；
- **运动排行榜**：每行原来写着"今日 · …""未带步数"这类占位文字，现在是
  **名次 + 距离 + 多久前 + 步数**；点台站改成了与全应用一致的底部面板；榜单只统计
  **今天**听到的（三天前的步数不会再排在今天前面），并且自己也在榜上、会标出来。
