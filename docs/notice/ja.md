# v1.6.156 をリリース：スマートビーコンが「曲がったら」打点できるようになりました

今回の更新は**軌跡とビーコン**が中心です：

- **スマートビーコンに3つ目の条件**：これまでの「タイマー」「距離」に加えて、
  **方位が大きく変わったら打点**できるようになりました。山道は速度が遅く距離の条件に
  なかなか届きませんが、ヘアピンカーブこそ軌跡が必要な場所です。設定した角度を曲がると
  点を補います。角度は**段ごとに設定可能**（10〜180°、0 = オフ）。

- **リアルタイム軌跡のサンプリングを1秒に**：以前は10秒に1点で、カーブが斜線になって
  いました。サーバーへ実際に送った点は地図上に**オレンジの小さな菱形**で表示されます。

- **台站備註（コメント欄）が入力できると分かるように**：設定のその行は以前ただの空白で、
  タップできることが分かりませんでした。

詳細は[リリースノート](https://github.com/dariondong/APRSLocus/releases)、
使い方は[ユーザーマニュアル](https://aprslocus.theez.top/manual/)をご覧ください。
