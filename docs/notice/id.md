# v1.6.156 sudah rilis: smart beacon kini bisa memancar saat berbelok

Rilis ini soal **jejak dan beacon**:

- **Kriteria ketiga untuk smart beacon**: selain *timer* dan *jarak*, kini bisa
  **memancar saat arah berubah cukup besar**. Di jalan pegunungan kecepatan rendah
  sehingga ambang jarak lama tercapai, padahal tikungan tajam justru tempat jejak
  paling penting. Sudutnya **bisa diatur per tingkat** (10–180°, 0 = nonaktif).

- **Sampling jejak langsung diperhalus ke 1 detik**: dulu satu titik tiap sepuluh
  detik sehingga tikungan tergambar sebagai garis miring. Titik yang **benar-benar
  dikirim ke server** kini ditandai berlian oranye kecil.

- **Kolom komentar stasiun kini terlihat bisa diisi**: baris itu dulu kosong dan
  tidak ada yang tahu bisa diketuk.

Lihat [catatan rilis](https://github.com/dariondong/APRSLocus/releases) dan
[panduan pengguna](https://aprslocus.theez.top/manual/).
