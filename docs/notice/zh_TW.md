# TOUCH SKY · 2.0 更新公告 · What's New

**1.5.8 → 2.0 · 322 次更新**

從純網路到射頻，從「看見」到「抵達」——這是 2.0 這一整條路的全部腳印。

**APRSLocus 2.0 將於 9 月 25 日 22:00 正式推送**，屆時可在 GitHub Releases 下載最新版。

親愛的 APRSLocus 同行者：

1.5.8 之後，我們寫下了 **322 次更新**。這不是數字，是一條從「網路裡的一個光點」走到「天空中一聲回應」的路。以下是這一整條路的全部腳印。

**一、介面 · 全新 UI 2.0**：以地圖為底層的版面，地圖常駐整屏、其餘內容放進可拖曳面板，顯示設定裡可切回 1.0；底部懸浮膠囊導覽（滑動指示膠囊）＋右上懸浮膠囊（天氣 / 連線 / 定位）；把手加大到 44px 且整頁可拖；橫向在手機 / 平板 / 桌面三端統一為左欄 + 地圖；移除頂部搜尋框、返回鍵回到地圖、補回天氣與一鍵連線；16 個頁面新增「首次進入小提示卡」。

**二、材質與主題**：新增霧面玻璃（Acrylic）與雲母（Mica）材質，另有「滿血霧面」檔；主題的顏色 / 圖示 / 文字可自訂，支援背景圖與匯出 JSON（可帶圖）；更多權杖、介面鬆緊與字型、分頁籤強調色；備份與還原把設定與資料匯出成一個 JSON。

**三、地圖 · 沉浸地圖**：多圖源（高德 / 衛星 / 向量免 Key / Carto / OSM / OpenTopo / Esri）；新增沉浸地圖頁（導航風格，左側附近台站）；台站篩選可套用到地圖；離線地圖按區域下載；移除聚合；歷史軌跡回放（點進某天，動畫重播）。

**四、台站與識別**：接入 aprs.org 官方裝置庫，自動識別廠商 / 型號 / 類別；內建 37 個符號表、3571 個標準圖示；台站操作選單（收藏 / 複製呼號 / 刪除）與 APRS.tv 查詢；APRSlocus 平台識別（不再一律歸為手機 App）；打點演算法重做（舊幀、重複幀、錯包與模糊位置都不再騙人）。

**五、訊息與翻譯**：單聊群聊統一會話 + ACK 確認；群聊重構（建群 / 邀請 / 成員 / 離開，no-ack 廣播）；聊天翻譯介面從 4 家擴到 7 家，預設自動、預設走免費免金鑰介面；支援雙向翻譯、對照顯示、傳送前翻譯、語言自動識別與記憶。

**六、連線與射頻**：新增藍牙 TNC（完整 KISS，真正修好「能收不能發」）與音效卡 TNC（AFSK 1200，手機 + 一條音源線即 TNC）；新增 PKWDWPL（Kenwood 航點，唯讀）與閘道（iGate）；多資料來源可同時接收、發射來源單獨指定；內建鏈路自檢；修「TNC 與 PKWDWPL 同裝置瓜分資料」與「音訊發射對方解不出」。

**七、定位與信標**：iOS 原生定位、macOS 改原生定位；網路粗定位不再自動上報；自身定位靜止防抖；智慧信標支援「按轉彎」（先分清真轉彎與 GPS 抖動）與「按距離」打點；軌跡取樣細化並標出信標點；軌跡與資料包上限可設定。

**八、天氣 · 傳播 · 建議**：天氣面板（即時 + 高低溫 + 體感 + 濕度 / 氣壓 / 露點 / 風向 / 能見度 / 雲量）；業餘無線電建議按「安全警示 > 注意 > 通聯機會 > 操作提示」分級，含灰線、雨衰、結冰駐波、大氣波導；短波 / 電離層傳播逐波段日 / 夜條件，6m 單獨預測。

**九、桌面小工具（Android）**：天氣 + 業餘無線電提示（4 檔尺寸自適應）、短波傳播小工具、系統狀態小工具；真實圖示與圖形 logo；支援縮放與暗黑模式；新增設計預覽工具。

**十、資料 · 匯出 · 備份**：ADIF 匯出（頻率可自訂、匯出選項可選）；修匯出路徑與檔名；資料包主控台（原始 / 解析、手動注入、分類篩選）；新增台站面板內的統計檢視。

**十一、裝置整合**：Garmin App 分享短鏈（gar.mn）與 LiveTrack；藍牙心率帶（BLE 0x180D）心率隨信標上報；裝置頁新增「其他資料來源」。

**十二、多語言與在地化**：介面語言增至 6 種（簡體 / 繁體 / English / 日本語 / Indonesia / Español）；多批中文硬編碼清理；榮譽牆與贊助名單多語言化。

**十三、社群 · 榮譽 · 公告**：榮譽牆展示每枚徽章的取得條件，含「開發人員」「FIRST FIX · 至高榮譽」「早期成員」；贊助牆補齊遺漏；應用內公告橫幅取自官網 Markdown。

**十四、平台 · 效能 · 穩定**：iOS / macOS / 桌面三端支援與橫向打磨；修「越用越卡」的 APRS-IS 重建 + socket 洩漏；霧面玻璃與動態背景效能最佳化；大量回歸測試與靜態檢查。

以及數不清的修復：關於頁卡片貼住下個區塊、底圖切換面板彈不出來、圖層面板點了沒反應、會話輸入框藏底下、「在地圖查看」不回地圖、天氣面板點空白關不掉…… 它們共同構成了從 1.5.8 到 2.0 的 322 次更新。
