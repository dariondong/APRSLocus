# 📡 2.0.4 已發布 · 此前撤回的功能已正式回歸

**2.0.4 已正式發布。** 此前因**版本號在正常發版流程之外被提升**而撤回的那批功能（位置報文資料擴充 `/A=` 高度與 PHG 功率 / 天線高度 / 增益、獨立狀態報文及其顯示），已在**去掉版本號變更**之後按正常流程重新合併，並隨本次正式版本發布。

如果你現在還在 2.0.3，請升級到 **2.0.4**（2.0.3 仍屬非正常發行，原因見下）。

---

## 一、本次發布包含什麼

- **位置報文資料擴充（PHG）**：設定 → 電台 → 臺站備註 →「進階設定」可填功率（瓦）/ 天線高度（英尺）/ 增益（dB）。填任一項即附上固定 7 位元組的 `PHGphgd`；量化照 APRS101 做（功率只取不超過實際值的最大檔 —— 報大了等於虛報涵蓋範圍），設定頁會把真正會送出去的內容回顯出來。報文裡的位置也照規範：`PHG` **緊跟符號**。
- **高度（`/A=`）**：可手填海拔，**留空則跟隨定位**（預設行為不變）。
- **獨立狀態報文**：可填狀態文字，與位置報文共用一個「發射」按鈕；留空時送內建的 `APRSlocus CONNECT` 在線幀。收下來的狀態報文會顯示在臺站詳情與地圖資訊窗。
- **若干修正**：發射按鈕會先查連結、沒有定位時如實說明、狀態報文用自己的連線文案、地圖頁「距下次上報」每秒刷新、裝置頁「連結自檢」不再重複標題、手機電量開關仍在信標頁。

完整內容見更新日誌。

[▶ 前往下載 2.0.4](https://github.com/dariondong/APRSLocus/releases/tag/v2.0.4)

> 升級前建議先做一次備份（設定 → 備份與還原）；Android 若提示簽章衝突無法覆蓋安裝，請先備份，再解除安裝舊版後安裝。

---

## 二、關於 2.0.3：仍建議不要使用

**2.0.3 仍屬非正常發行。** 它源於一次**在正式發版流程之外把版本號從 2.0.2 提升為 2.0.3** 的變更，並據此生成了發行版。

APRSLocus 會把版本號**發送到空中**（APRS-IS 與射頻的身分幀 / 在線幀裡都帶著它）。如果出現兩個都自稱 **2.0.3** 的安裝包，在 aprs.fi 這類平台上就**無法分辨**到底是哪一個在發信標 —— 出了問題也沒法定位。因此該版本已從 Release 與官網撤回。

若你安裝過 2.0.3，請**升級到 2.0.4**。

---

## 三、一條規則：版本號只由維護者在發版時提升

功能貢獻照常歡迎 —— 提 Issue、回報問題、提交 PR 都可以；需要共同遵守的只有一條：**不要改動版本號**，它只在正式發版時由維護者統一提升。
