## 🚀 2.0 更新內容（1.5.8 → 2.0，322 次更新）

### 全新 UI 2.0
以地圖為基底 + 可拖曳面板 + 懸浮膠囊導覽；橫向三端重做；霧面玻璃 / 雲母材質。

### 連線與射頻
藍牙 TNC（完整 KISS）、音效卡軟 TNC（AFSK 1200）、PKWDWPL、iGate；多資料來源可同時接收，發射來源單獨指定；內建鏈路自檢。

### 訊息與翻譯
單聊群聊統一會話 + ACK；翻譯介面 4 → 7，預設免金鑰；雙向翻譯、對照顯示、發送前翻譯、語言自動記憶。

### 地圖與定位
多圖源、沉浸地圖、離線地圖、歷史軌跡回放；移除聚合；智慧信標（依轉彎 / 依距離），靜止防抖。

### 臺站識別
接入 aprs.org 官方裝置庫，識別廠商 / 型號 / 類別；內建 37 符號表、3571 圖示。

### 天氣 · 傳播 · 小工具
業餘無線電建議分級（安全警示 > 注意 > 通聯機會 > 操作提示）、短波電離層逐波段日 / 夜條件、Android 三種桌面小工具。

### 個人化與資料
佈景主題自訂 + 背景圖 + JSON 分享、備份與還原、ADIF 匯出、統計面板。

### 多語言與裝置
6 種介面語言；Garmin LiveTrack、藍牙心率帶。

以及 322 條裡數不清的修正。

## ⚠️ 升級前必讀

- **v1.4.9 之前的老版本**：因 Android 簽章金鑰變更，**無法直接覆蓋安裝**。請先**備份**呼號、臺站備註、自訂主題等重要設定，然後**解除安裝舊版**，再安裝新版。
- **v1.4.9 及之後版本**：通常可直接覆蓋升級，建議升級前同樣做好備份。
