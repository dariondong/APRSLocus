## 這次加了 6 條

1. **3.5 閘道轉發要自己負責**：把 APRS-IS 收到的報文轉到射頻發射（閘道 / iGate），等於
   **代表他人在業餘頻段上發射** —— 呼號、頻率、功率、工作方式都得合法合規；
2. **3.6 未成年人**：應在監護人同意與指導下使用，由監護人承擔後果；尤其不得在沒有
   相應資格的情況下進行射頻發射；
3. **3.7 送出去的內容**：APRS 是公開、跨國的網絡 —— 內容要真實、準確、合法，並尊重
   不同國家和地區的法律、宗教與文化習俗；
4. **5.3 會讓哪些第三方看到什麼**：查天氣會傳送位置、翻譯訊息會傳送待翻譯文字、檢查
   更新會向 GitHub 請求版本、佳明 LiveTrack 會存取你填的連結、地圖圖磚來自多個第三方
   —— **不使用這些功能就不會發生**；
5. **7.6 「生命守護」等不是醫療設備**：碰撞 / 摔倒偵測、心率告警只是基於手機感測器與
   定位的輔助提醒，可能漏報、誤報或延遲，**不是緊急救援服務**；緊急情況請直接撥打
   當地急救電話；
6. **9.4 關於贊賞**：贊賞完全自願，不換取任何功能、優先支援或服務承諾，且不予退還；
   未成年人請先取得監護人同意。

## 這一版順手修了什麼

- **修好了「藍牙連不上就閃退」**：那是把阻塞的藍牙連線放在主執行緒上，系統會判定
  「應用程式無回應」並把它關掉；現在連線在工作執行緒進行，失敗也會如實回報；
- **手機電量不再「半天不動」**：以前只在有定位時才讀一次，手機放著不動就會被凍住；
- **運動排行榜**：每列原本寫著「今日 · …」「未帶步數」這類佔位文字，現在是
  **名次 + 距離 + 多久前 + 步數**；點台站改成與全應用程式一致的底部面板；榜單只統計
  **今天**聽到的（三天前的步數不會再排在今天前面），而且自己也在榜上、會標出來。
