# 📢 使用者條款更新到 V1.2：不提供任何伺服器位址與網際網路服務

**使用者條款更新到 V1.2（2026 年 10 月 2 日）。** 這一版把「軟體到底碰不碰伺服器」說清楚，
並依條款第八節在應用程式內與 GitHub 公布；**繼續使用即視為接受**，全文：設定 → 關於 → 使用者條款。

---

## 這次說清楚了什麼

1. **不預置、不推薦任何伺服器**：軟體裡沒有任何伺服器位址或連接埠，**首次啟動與預設設定下
   不會連線**任何 APRS-IS、iGate 或其他網路伺服器 —— 連不連、連到哪裡，由**你自己填寫、
   自己決定**（所以首次引導裡的「伺服器」欄位可以留空）；
2. **不提供任何網際網路服務**：我們不營運 APRS-IS、iGate，也不做資料上傳、中轉或儲存；
   與任何第三方伺服器之間不存在隸屬、代理或合作關係；
3. **自行設定的責任**：你自己連的第三方伺服器，請自行確認該伺服器及你的使用行為合法合規，
   並自行承擔資料出境、個人資料處理、無線電管理等產生的責任；
4. **合法使用**：請使用本人合法持有的呼號，遵守《數據安全法》《個人信息保護法》等規定；
   禁止用於非法追蹤、騷擾他人或干擾網路；
5. **別亂發資料**：請勿發送國家秘密、商業秘密、個人隱私或敏感位置資訊 —— APRS 是明文的，
   可能被第三方接收、存儲或公開存檔。

## 這一版順手改了什麼

- **首次引導不再預填公共伺服器，也不再自動連線**：伺服器留空 = 一條網路都不拉，軟體只在本機
  運作；要連網請自行填寫你信任的伺服器與連接埠。原文案「可保持預設設定直接使用」一併改掉
  （那等於在推薦）；
- 條款 5.1 裡點名的伺服器位址已刪除。
