# 📦 2.0.13 · APRSlocusBOX —— 用手機管你那台小盒子

**2.0.13 已發布。** 這一版把「小盒子」（ESP32 + 螢幕 + 旋鈕那台）接進了應用程式：
「裝置」頁多了一條 **APRSlocusBOX** —— 連上之後，手機上就能讀它的設定、改它的設定、
把手機的位置餵給它、催它發一幀信標、看它到底在幹什麼。

**先說結論：沒有盒子的人什麼都不用做。** 這一版不需要你做任何設定，升級方式也沒變。

---

## 一、盒子推回來、手機上看得到

連上盒子之後，應用程式能看到它**自己報回來的**東西：

- 呼號 / SSID、鏈路模式（wifi / bt / both）、自動信標間隔、APRS-IS 伺服器、GPS 波特率；
- 發出去多少幀（TX）、發了多少次信標（BEACON）、收到多少則訊息（RXMSG）、
  確認了幾則（ACK）、錯了幾次（ERR），以及**最近一則事件原文**；
- 盒子推回來的 `EVT …` 事件與指令回執，全部進日誌，可一鍵複製 ——
  出問題時這就是唯一的證據。

## 二、手機也能替盒子做點事

- **改設定**：全部 23 個鍵都在（鍵名與盒子文件逐字一致），點一項就地改。
  改完應用程式會**自動回讀** —— 所以螢幕上顯示的是**盒子裡的真值**，不是你剛輸入的值；
- **餵位置**：把手機目前的座標餵給盒子（`POS lat lon [alt] [spd] [crs]`），
  也可以開「自動餵位置」（30 秒一次）。盒子沒裝 GPS 的時候，出門帶手機就能用；
- **催它動作**：立即信標 / 狀態報文 / 重連 APRS-IS / 清空台站 / 格式自檢 / **重啟盒子**
  （鏈路模式與藍牙這類「開機設定」改完要重啟才生效，現在不用拔電了）。

## 三、新：手機狀態給盒子（盒子的 PHONE 頁）

這一版還把**手機這側看到的東西**推給盒子：自己的速度、方位、海拔、有沒有定位、
APRS-IS 通不通、未讀訊息，以及**附近台站列表**（按距離排，最多 8 條）。

盒子那邊新增了一頁 **PHONE** 顯示這些，首頁底行也會寫一句 `PH 12km/h`；
頁頭有個 `P` 標記 —— **亮著**才說明手機正在推（120 秒沒推就變暗，不拿舊資料騙人）。

為什麼需要它：盒子只跑藍牙時**自己不上 APRS-IS**，「旁邊有誰」在它上面本來是空的；
就算在 wifi 模式，手機的過濾半徑與位置也未必與盒子相同 —— 兩邊對照著看才有意義。

## 四、兩條刻意的規矩

- **盒子不是「資料來源」**：它自己就上 APRS-IS、自己組報文，本應用程式再收一遍只會重複。
  所以它只作為「一台要管的裝置」出現在裝置頁，不進資料來源多選；
- **絕不自動發射**：信標與狀態報文必須你自己點（與「射頻發射永遠要顯式」同一條規矩）。
  自動的只有本地的位置餵養與狀態推送 —— 它們只寫盒子的位置與螢幕，**不上射頻**。

## 五、需要燒韌體嗎

需要。應用程式這一半（協定 + 介面）在這一版裡做完了；**盒子那半是另一份韌體工程**，
有盒子的人需要自己燒一次（盒子側同步新增了 PHONE 頁，也做了一次介面重做）。
沒有盒子的話，這一版對你沒有任何影響。
