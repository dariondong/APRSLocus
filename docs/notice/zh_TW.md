# ⚠️ 重要公告 · 2.0.3 已撤回，建議回退至 2.0.2

**2.0.3 屬非正常發行：它由一次在正常發版流程之外提升版本號的變更帶出。我們已把該版本從 Release 與官網撤回，建議仍在使用 2.0.3 的朋友回退到 2.0.2。**

---

## 一、發生了什麼

**v2.0.3 已經撤回。**

它源於一次**不合規的版本號變更** —— 在正式發版流程之外，專案版本號被從 **2.0.2** 提升為 **2.0.3**，並據此生成了發行版。

這違反了本專案的一條硬性規則：**版本號只能由維護者在正式發版時統一提升**，任何功能貢獻都不應改動它。因此 v2.0.3 屬於**非正常發行**，我們已完成以下處理：

- 刪除 GitHub 上的 v2.0.3 **Release** 及其**標籤**；
- 把官網與下載入口**回退到 2.0.2**；
- 將相關改動從主分支**整體回滾**。

---

## 二、建議：回退到 2.0.2

如果你已經安裝或正在使用 2.0.3，**建議回退到 2.0.2**。

- **Android**：下載並安裝 **APRSLocus_2.0.2.apk**；若提示簽章衝突無法覆蓋安裝，請先**備份**（呼號、臺站備註、自訂主題等重要設定），再解除安裝 2.0.3 後重新安裝。
- **Windows**：下載並執行 **APRSLocus_Setup_2.0.2.exe**。
- **iOS**：下載 **APRSLocus_2.0.2_unsigned.ipa** 自行簽章安裝。

[▶ 前往下載 2.0.2](https://github.com/dariondong/APRSLocus/releases/tag/v2.0.2)

> 建議回退前先做一次備份（設定 → 備份與還原），換機與降級都用得上。

---

## 三、為什麼版本號這麼重要

APRSLocus 會把版本號**發送到空中** —— 在 APRS-IS 與射頻的身分幀 / 線上幀裡都帶著它（形如 APRSlocus CONNECT v2.0.2）。

如果出現兩個都自稱 **2.0.3** 的安裝包，在 aprs.fi 這類平台上就**無法分辨**到底是哪一個在發信標：出了問題也沒法定位。版本號是這個專案在電波裡的身分，必須保持唯一，且只能由維護者在正式發版時提升。

---

## 四、後續安排

- 相關功能改動**不會丟**：它們會在**去掉版本號變更**之後，按正常流程重新提交、審核與合併，並隨下一個**正式版本**發布。
- 真誠感謝每一位參與貢獻、測試與回饋的朋友。提出新功能、回報問題、提交 PR 我們都非常歡迎；需要共同遵守的只有一條 —— **不要改動版本號**。

如果你對回退操作或版本號規則有任何疑問，歡迎在 QQ 交流群或 GitHub Issue 中提出。
