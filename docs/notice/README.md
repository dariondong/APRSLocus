# 这里放各语言的公告

`<语言>.md`，对应应用里的语言代码：

| 文件 | 语言 |
|---|---|
| `zh.md` | 简体中文（没写 zh_TW 时繁体也用这一份） |
| `zh_TW.md` | 繁體中文 |
| `en.md` | English（**兜底**：其它语言缺失时用这份） |
| `ja.md` | 日本語 |
| `es.md` | Español |
| `id.md` | Bahasa Indonesia |

应用侧行为（见 `lib/notice.dart`）：

1. 按当前界面语言取 `notice/<语言>.md`；
2. 取不到（404 / 超时 / 断网）→ 回退 `notice/en.md`；
3. 还是取不到 → 用**上次成功拉到的缓存**（存在 SharedPreferences 里，
   所以断网时公告依然看得见）；
4. 连缓存都没有 → 界面上如实写「暂无公告」，而不是留一片空白让人以为坏了。

写法建议：第一行 `#` 标题会作为横幅上的一行摘要，正文尽量短。
