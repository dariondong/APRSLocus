連線與訊息

為什麼收不到訊息 / 無法收發訊息？

絕大多數情況是 Passcode 未驗證。密碼填 -1 只能連接，不能正常收發訊息。請到 APRS Passcode 查詢 生成自己的 Passcode 並填入「連線設定」；若伺服器回傳 unverified，首頁頂部會出現黃色警告橫幅，點「去設定」即可直達。

Passcode 該怎麼設定？

在引導第 6 步或「設定 → 連線」中，用你的完整呼號（含 SSID 後綴，如 BG7LZQ-3）查詢生成 Passcode 後填入即可。

連線失敗 / 頻繁斷線？

應用內建漸進式重連（8 → 16 → 32 → 60 秒）。若持續失敗，請檢查網路、確認伺服器位址（預設 rotate.aprs2.net:14580）與埠是否被封鎖，或在「連線設定」中更換伺服器後點「重新連線」。

支援哪些資料來源？該怎麼選？

四條：網際網路 APRS-IS、藍牙 / 串列埠 TNC（KISS）、音效卡音訊 AFSK 1200，以及 Kenwood 電台的 $PKWDWPL（只收不發）。剛上手選 APRS-IS 即可；有電台想聽射頻，再加 TNC 或音訊。數條鏈路可同時收報文，發射來源單獨指定一條。

閘道（iGate）是什麼？需要開嗎？

iGate 把你在射頻上聽到的報文轉到 APRS-IS，讓全球網路看到你附近的臺站。只有「在聽射頻、且願意貢獻」時才需要。具備環路防護（含 TCPIP* 或已有 q 構造的報文絕不回送）與 30 秒去重，預設關閉。

藍牙 TNC 連上了，但收不到 / 發不出？

先升級到最新版：v1.6.110 修了「TNC 與 PKWDWPL 綁定同一臺設備、互相瓜分接收資料」，v1.6.112 找到「能發不能收」的真正原因。升級後仍異常，用「鏈路自檢」分層排查，並確認 Android 已授予藍牙與定位權限。

音效卡音訊（AFSK）怎麼接？對方解不出怎麼辦？

耳機 / 麥克風埠接電台的 SPK / MIC，設定好 PTT。發射時應用會把媒體音量拉滿並暫停麥克風，鏈路自檢裡能看到電平；對方解不出，先查電平與接線。

定位與信標

手機上收不到周邊臺站？

檢查「接收篩選」是否勾選了目標國家 / 地區，並確認接收範圍（經緯度 + 半徑）覆蓋你的位置。預設只接收中國（B 開頭）臺站。

背景定位會一直耗電嗎？

Android 端使用前景服務持續定位以保持 APRS 在線，可在「定位 / 信標」設定中調整上報間隔，或關閉信標上報、按需手動上報來降低耗電。通知欄可一鍵「結束」應用。

站著不動時我的標記亂跳 / 軌跡有毛刺？

v1.6.146 給自身定位加了「靜止防抖」；v1.6.149 再用加速度計判斷「有沒有在動」、低速時用指南針補航向（Android，預設開啟，可在「設定 → 信標 → 定位」關）。升級到最新版即可。

歷史軌跡在哪看？和地圖上那條有什麼區別？

「設定 → 歷史軌跡」按天保存在本機，可看總里程、平均與最高速度、移動時長，退出重進還在；點某一天還能在地圖上回放當日路線（可拖進度、0.5×~4× 倍速）。它與地圖上那條「我的軌跡」刻意分開：那條只服務本次顯示，退出即失、確認位置跳變時整條清空。

介面與地圖

Windows 上地圖顯示異常？

建議在「顯示 → 地圖類型」中切換為向量地圖（無需 API Key，相容性最好），或使用 Carto / OSM / Esri 等國際圖源。

怎麼換介面風格 / 切回舊佈局？

「設定 → 顯示」裡可切 UI 2.0（以地圖為基底）與經典佈局，還能選磨砂玻璃 / 雲母材質（v1.6.138）。主題支援顏色、圖示、文字與背景圖（17 個顏色權杖），可匯出 JSON 分享。

臺站為什麼不再合併成一顆球？

v1.6.149 起去掉聚合：向量地圖與自繪地圖都是一臺站一個標記。低縮放時的密度交給熱力圖，工具列裡有開關。

離線地圖怎麼用？斷網能看嗎？

「設定 → 顯示 → 離線地圖」把當前視圖的瓦片一次下載到本機（斷點續傳、單區域上限 20 萬張），斷網、無訊號也能看，另有「僅離線模式」。Web 版不提供下載。

支援哪些語言？翻譯要金鑰嗎？

介面六種語言：簡體中文、繁體中文、English、日本語、Indonesia、Español。聊天翻譯預設走免費介面、無需任何金鑰，可雙向、可對照，也能發送前先把輸入譯成對方的語言。

桌面小組件與短波

桌面小組件怎麼添加？為什麼是空的？

長按桌面 → 新增小工具 → APRSlocus，有天氣、短波、系統狀態三套。小組件不自己連線，資料由應用單向推送 —— 裝好後先打開一次應用；升級後若空白，打開應用刷新即可。

短波面板的資料準嗎？多久更新？

來自 hamqsl.com（N0NBH 整理，業餘界事實標準），來源約每小時更新，應用快取 30 分鐘。注意它是全球 / 區域平均，不是你所在地的實測值。

小組件能調大小嗎？

天氣小組件四檔自適應；v1.6.133 起短波與系統狀態也能拖曳縮放，拉高會自動換「加高檔」。

資料、備份與安裝

換手機 / 重裝怎麼遷移？

「設定 → 備份與還原」把設定與資料匯出成一個 JSON，新裝置匯入即可（v1.6.123）。匯入後需重啟應用生效。

怎麼匯出通聯日誌？

資料匯出為 ADIF —— 業餘無線電通用的日誌交換格式，頻率可自訂，匯出後可直接匯入其它日誌軟體。

覆蓋安裝提示簽名衝突 / 版本降級？

自 1.5.2 起 Android 使用正式 release 簽章，CI 與本地簽章一致，直接覆蓋安裝即可。若從更老版本升級，請解除安裝後重裝。

在哪裡下載？怎麼更新？

GitHub Releases 與 GitCode 雙管道；應用內「檢查更新」按平台分流，也能安裝歷史版本。本站導覽「下載」直達最新版。
