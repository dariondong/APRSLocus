    三套桌面小組件#

    Android 主螢幕長按 → 小組件 → 找 APRSLocus：

    小組件內容
    天氣圖示、溫度、現象、今日高低溫 + 指標格 + 火腿建議；按主螢幕空間自動切 4 檔佈局（主檔 / 豪長 / 緊湊 / 單行）
    短波各波段「日 → 夜」條件色帶，一眼看出現在該用哪一段
    系統狀態鏈路、定位與計數的即時快照
    1. 新增小組件 → 先打開一次應用（小組件要應用推資料）。
    2. 升級後若顯示空白：再打開一次應用即可刷新。
    📲

    小組件不自己連線：應用把已計算、已本地化的快照單向推給原生算繪 —— 天氣介面金鑰只在應用側，不會外洩到小組件。

    短波傳播面板#

    • 資料來源：hamqsl.com（N0NBH 整理，業餘界事實標準）；來源約每小時更新，應用快取 30 分鐘。
    • 看什麼：SFI / Kp / A 指數、黑子、X 射線、太陽風；四個波段對的日 / 夜條件一目了然，另有 6m 預測。
    • 怎麼看：綠色好、黃色湊合、紅色差 —— 先挑「日」或「夜」裡顏色最好的那一段。
    誠實

    hamqsl 的條件是全球/區域平均，不是你所在地的實測值 —— 出門前請結合本地時間、天線與雜訊底再判斷。
