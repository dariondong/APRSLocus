    先用這三個入口#

    1. 鏈路狀態卡（首頁頂部）——連線是否成立、收發計數、伺服器回傳值。 回傳 unverified = Passcode 問題（去填）。
    2. 鏈路自檢（裝置頁）—— TNC 協定回路、AFSK 調變解調回路，一鍵分層定位； TNC 另有初始化字串與發射自檢（狀態封包，不含座標）。
    3. 封包頁—— 原始封包到底有沒有進來。能收到但不上圖 = 篩選/座標問題， 回臺站與篩選；一條都沒有 = 鏈路問題，回第 1、2 步。

    症狀 → 原因 → 動作#

    症狀最可能的原因動作
    黃色「未驗證」橫幅Passcode 空 / 錯設定 → 連線 → 填正確 Passcode → 儲存並套用
    連不上伺服器網路 / 伺服器位址 / 埠核對 rotate.aprs2.net:14580；斷線會自動 8→16→32→60s 重連，等一輪
    封包頁一條都沒有沒勾資料來源 / 範圍過濾太窄設定 → 連線：勾 APRS-IS；範圍半徑調大 → 儲存並套用
    收到但地圖上看不見列表篩選擋住了臺站頁點「清除篩選」；核對狀態/類型篩選
    自己位置不顯示/亂跳沒定位權限 / 用了網路粗定位給定位權限；設定 → 定位上報 → 定位模式選純 GPS
    TNC 能收不能發停在命令模式 / 線速不匹配送出初始化字串（KISS ON）；核對 9600~115200 與電臺一致
    音訊對方解不出發射電平過低或削波 / 用錯線調整發射電平；耳機孔 → 電臺資料/麥克風孔，勿用喇叭對麥克風
    訊息發出去沒反應超 67 字元 / 512 位元組；對方不在线縮短內容；看氣泡狀態，逾時即失敗
    群組收不到射頻模式不支援群廣播；Passcode 未驗證切到 APRS-IS 發；先修 Passcode
    閘道計數不漲缺一個來源（APRS-IS 或射頻）/ 射頻收到=0按介面提示補齊來源；射頻收到=0 先查電臺音量/靜噪/天線
    桌面小組件空白小組件沒有資料（應用沒打開過）打開一次應用刷新
    離線地圖斷網打不開沒下載該螢 / 未開僅離線移到目標螢下載；開「僅使用離線圖磚」
