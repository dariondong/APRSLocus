    匯出 ADIF 備份與恢復 歷史軌跡與回放

    匯出 ADIF#

    1. 入口：設定 → 匯出 ADIF。
    2. 頻率可自訂（ADIF 是業餘無線電通用日誌交換格式）。
    3. 匯出的檔案可直接匯入其它日誌軟體。
    ✅

    驗證：匯出後用任意日誌軟體開啟，能看到呼號、時間、模式欄位即成功。

    備份與恢復#

    1. 匯出（設定 → 備份與恢復 → 匯出備份）：設定組態（電臺、信標、地圖、篩選、資料來源、伺服器等） 與本地資料進一個 JSON；可勾選是否包含圖片。
    2. 匯入：選擇備份檔案（或從剪貼簿貼上）→ 匯入後重啟應用生效。
    3. 換機 / 重裝的順序：裝應用 → 匯入 → 重啟 → 核對「設定 → 連線」的伺服器與 Passcode。
    🔐

    白名單匯入：只認該分組白名單內的鍵 —— 來路不明的 JSON 改不了內部設定； 更高版本的備份會被拒絕並提示先升級。備份檔案含呼號、伺服器口令與 API 金鑰，請妥善保管。

    平台差異：Android 用系統檔案選擇器（下載目錄）；Windows 存 Documents；Web 版走剪貼簿。 讀取上限 32 MB。

    歷史軌跡與回放#

    1. 入口：設定 → 歷史軌跡。
    2. 按天落盤：tracklog/YYYY-MM-DD.json，記錄經緯度、速度、航向、海拔、精度 —— 退出重進還在。
    3. 每天一屏：總里程、平均與最高速度、移動時長、軌跡點數；可按天刪除或一鍵清空。 移動時長只累計確實在動的段 —— 中途停車吃飯的兩小時不算開車。
    4. 點進某天可回放：底圖與主地圖同一套（同快取、同座標校正）；軌跡隨播放生長、可拖進度、 0.5× ~ 4× 倍速、可跟隨視角；超過 45 秒的停頓自動快進。
    5. 地圖上該怎麼看這條線：螢幕軌跡按 GPS 1 秒取樣，落點還要滿足「位移夠」或「隔 5 秒且確實挪了」 —— 所以轉彎不會被切成斜線，慢走也不會稀稀落落。發到伺服器去的那些點另用橘色小菱形標在軌跡上， 數量與間隔一眼可見（軌跡點會被抽稀、封頂，菱形不會：那是已經送出去的事實）。
    🧾

    它與地圖上那條「我的軌跡」刻意分開：螢幕軌跡只服務本次顯示，退出即失； 歷史軌跡是留檔，可匯出、可回放。
