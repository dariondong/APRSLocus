    定位上報#

    定位上報#

    GPS · 信標 · 手動定位

    三件事：用什麼定位（GPS / 網路 / 手動）、多久報一次（預設 60 秒、最短 5 秒）、報什麼（速度/方位角/電量可關）。

    定位來源

    選擇座標來源

    ℹ️

    無法自動定位時，可手動輸入經緯度或用地圖選點，用於信標上報與臺站距離計算。

    設定項控件預設值說明
    定位模擬位置 useSimLocation選項卡關使用裝置定位 / 模擬位置：手動輸入座標
    感測器輔助定位 sensorAssist開關開用加速度計判斷是否真的在移動、用指南針補正低速航向，讓軌跡打點更準（僅 Android 生效）。

    TNC 初始化字串

    連線後逐行傳送（等價 APRSdroid 的 kiss.init）

    ℹ️

    若 TNC「能收不能發」，先在這裡試：很多藍牙/序列 TNC 模組上電停在命令模式，必須先收到 KISS ON、RESTART 等指令才進入 KISS 轉發狀態。每行一條命令（傳送時自動補 CRLF）。

    設定項控件預設值說明
    行間隔 (ms) initDelayMs輸入框300每行命令之間的等待時間。模組處理命令需要時間，太短會丟命令
    串列埠線速 (bd) serialBaud輸入框9600USB 串列線與電台資料埠必須同速，否則一個位元組都收不到。常見值：9600 / 19200 / 38400 / 57600 / 115200。藍牙 SPP 沒有線速概念，綁藍牙裝置時此項不生效。
    立即傳送初始化字串按鈕—

    KISS 參數

    直接下發到 TNC 的鏈路層參數

    設定項控件預設值說明
    連線後下發 KISS 參數 pushKissParams開關關預設關閉（與 APRSdroid 一致）。打開後連線時會把上面的參數推給 TNC，覆蓋它自己的設定 —— 參數不合適可能讓它一直退避而不發射，所以只在需要統一管理時打開。
    發射延時 (ms) txDelayMs輸入框300KISS TXDELAY，單位 10ms。發射前留給自己 PTT 建立的時間
    發射尾音 (ms) txTailMs輸入框50KISS TXTAIL，單位 10ms。某些電台需要尾部保持才能收全
    持續度 P persistence輸入框63KISS PERSISTENCE，0-255。越小越禮讓，共用信道時能減少碰撞
    時隙 (ms) slotTimeMs輸入框100KISS SLOTTIME，單位 10ms。與持續度共同決定信道競爭節奏
    全雙工 fullDuplex開關關
    信道 / KISS 埠 channel輸入框0多信道 TNC 才有多埠，單信道電台保持 0
    幀長上限 (位元組) maxFrame輸入框330超過此長度的報文不會發出（1200bd 下 AX.25 單幀約 330 位元組）
    射頻中繼路徑 path輸入框WIDE1-1,WIDE2-1射頻上使用的中繼，如 WIDE1-1,WIDE2-1；留空則不指定
    廠商命令碼 hardwareCmd輸入框-1KISS SETHARDWARE (0x06)，廠商自訂；-1 表示不下發
    參數值 hardwareVal輸入框0KISS SETHARDWARE (0x06)，廠商自訂；-1 表示不下發

    回到 TNC 命令模式按鈕—

    取樣率 sampleRate輸入框2205022050Hz 是音效卡 TNC 常用值；裝置不支援時改用 44100/48000。修改會重啟擷取

    標號頻率 (Hz)輸入框—Bell 202 規定標號 1200Hz、空號 2200Hz；只有 ±幾 Hz 的容差，不要隨意改
    空號頻率 (Hz)輸入框—空號音調。與標號音調一起決定 FSK 頻偏（標準為 1000Hz）
    發射前導 (ms) txDelayMs輸入框300發射前導時長：給對端解調器鎖定時間、給電台 PTT 建立時間

    音訊發射

    發射前先聽通道，避免與其他台站碰撞

    設定項控件預設值說明
    允許發射 txEnabled開關開關閉後只接收不發射（只想聽信標時最省心）
    允許射頻信標 rfBeacon開關關打開後才會在射頻上定時發射位置。發射需以自己的呼號並在執照範圍內操作
    發射前等待通道空閒 (ms) csmaWaitMs輸入框3000偵測到通道佔用時最多等待多久；0 = 不等待直接發射
    射頻中繼路徑 path輸入框WIDE1-1,WIDE2-1射頻上使用的中繼，如 WIDE1-1,WIDE2-1；留空則不指定
    幀長上限 (位元組) maxFrame輸入框330超過此長度的報文不會發出（1200bd 下 AX.25 單幀約 330 位元組）
    發射電平唯讀狀態—發射前系統會把媒體音量拉到最大、並暫停麥克風擷取；峰值太低或削頂都會讓對端解不出
    自動回覆 ACK autoAck開關開關閉後不回覆收到的訊息回執，可減少射頻佔用
    斷開後自動重連 autoReconnect開關開
