Web 版的取捨

⚠️

Web 版是「能看、能連」的輕量形態：

  • 不提供離線地圖下載（瀏覽器沒有穩定可寫目錄）；
  • 備份走剪貼簿（複製 / 貼上），不落檔案；
  • 即時音訊在不支援的平台會提示，仍可用 WAV 模式（上傳錄音離線解碼）；
  • 無桌面小組件、無背景持續定位。
