    六條鏈路：兩條在網際網路，四條接電臺#

    入口 設定 → 伺服器。這一頁只擺兩台網際網路伺服器，一台一張卡，卡上有自己的開關，點進去才是它的位址與口令。

    鏈路走什麼收發
    APRS-IS網際網路 TCP，位址自己填✓✓
    APRSNETCN SERVER同一套協定的國內伺服器，位址自己填✓✓
    TNC藍牙 SPP 或 USB 序列埠，KISS 協定✓✓
    音訊耳機孔接電臺，AFSK 1200（Bell 202）✓✓
    WLAN 電臺直連Wi-Fi 直連 Icom 電臺（IC-705 / IC-9700 等）✓✓
    PKWDWPL讀 Kenwood 輸出的航點語句✓✗ 唯讀

    發射要分兩行選。「位置與狀態封包」可以同時勾幾條鏈路，兩條網際網路鏈路一起發也不會撞包。「訊息」只勾一條，它只認自己那條鏈路，沒連上就發不出去。

    📡

    接收範圍預設 300 km（最小 10 km），規則是 r/緯度/經度/半徑。改完要點 「儲存並套用過濾」 才生效。

    接上 APRS-IS#

    兩條網際網路鏈路是平的，APRS-IS 不特殊。它的參數都在自己的子頁裡，與 APRSNETCN 那張卡各管各的。

    1. 設定 → 伺服器 → APRS-IS 伺服器，填伺服器位址與連接埠 14580。位址留空就連不上，軟體不預置伺服器。
    2. 填 Passcode：用完整呼號產生，見 快速上手。留空或 -1 只能收，訊息發不出去。
    3. 打開卡片頂部的開關。首頁本來連著的話這一條會自己連上，沒連著就回首頁點連接。
    4. 看鏈路狀態卡：顯示已連接，收封包計數開始漲。
    • 位址、連接埠和 Passcode 改了自動儲存，不用再點按鈕。
    • 斷線自己重連：8 → 16 → 32 → 60 秒逐步退回。
    • 伺服器回 unverified 就是 Passcode 沒通過，回第 2 步。
    • 要走自建中轉就填 WebSocket URL，留空走標準 TCP。

    第二條鏈路：APRSNETCN#

    APRSNETCN 與 APRS-IS 並列。它跑同一套 APRS-IS 協定，伺服器在國內，位址同樣要自己填。收發都能走它，只連它一條也能用。

    1. 設定 → 伺服器 → APRSNETCN SERVER，填位址與連接埠。
    2. 填 Passcode。伺服器給過帳號與口令的，把這兩格也填上。
    3. 打開開關，看卡片裡的鏈路狀態。
    4. 要 24 小時臺站就在卡片下面點同步，收下來的臺站與 APRS-IS 的併在一起。
    • 登入結果單獨一行。口令錯了鏈路會連上又斷開，原因只寫在這裡。
    • 兩台同時在線時同一則封包只記一次，兩邊各收一份也不會重複計數。
    • 換了位址或口令後點卡片裡的重連，新參數才生效。

    雲端同步：訊息與軌跡存到伺服器#

    雲端同步把訊息與歷史軌跡存到伺服器上。換一台裝置，登入同一個帳號就能拉回來。它掛在 APRSNETCN 那一頁，整塊可以關掉。

    1. 設定 → 伺服器 → APRSNETCN SERVER，往下就是雲端同步那幾張卡，先填帳號與口令。
    2. 點登入。登入後卡片換成帳號與雲端的三行數字。
    3. 同步方式選 關閉 / 手動 / 自動，自動那檔可以選 5、15 或 60 分鐘一輪。
    4. 把想同步的那一類打開：訊息、歷史軌跡，各一個開關。
    5. 要馬上同步點「立即同步」，要清掉雲端那份點「清空雲端資料」。
    • 帳號就是伺服器接入名單裡那條，與 APRSNETCN 鏈路頁填的是同一個。
    • 位址跟著 APRSNETCN 那條鏈路走，這裡沒有第二個位址。換伺服器要重新登入，舊位址上的資料不搬。
    • 同步的是訊息與按天的歷史軌跡。應用設定與主題在「備份與還原」頁。
    • 兩台裝置同一天都記了軌跡，讀回來是一條線。時間差 3 秒內、距離 50 公尺內算同一個點。
    • 「登入的裝置」裡是登入過這台伺服器的裝置，本機帶標記。移除一台，它下次同步要重新登入。
    • 連線是明文 HTTP，口令與內容不加密。口令登入後從本機清掉，權杖留在本機，登出即丟棄。
    • 到「設定 → 功能」可以把雲端同步整塊關掉。關掉之後不再連網，兩條鏈路照舊。

    外接 GPS 模組#

    外接 GPS 是一台藍牙 NMEA 模組，接上以後由它供位置。它的定位比手機穩，也省手機的電。它不是一條 APRS 鏈路，只負責告訴應用你在哪。

    1. 設定 → 裝置 → 外接 GPS。
    2. 點掃描裝置，選中模組後綁定。模組走藍牙 SPP，要先在系統裡配對。
    3. 連接成功後看「目前定位」：緯度、經度、衛星數和精度都在這一塊。
    4. 要衛星數隨信標送出去，去 設定 → 定位上報 打開「衛星數」。
    • 模組在位時手機定位自動待機。模組掉線會切回手機 GPS，日誌裡寫一句。
    • 「嚴格校驗和」預設開，語句校驗不符直接丟棄。排查相容性問題時可以關掉，改成只標註。
    • 語句計數在漲但沒有定位，多數是室內收不到星。語句不漲就查藍牙這一層。

    接電臺：TNC / 音訊 / PKWDWPL / Icom#

    四條射頻路徑的入口都在 設定 → 裝置（裝置總覽頁列出當前鏈路與四個子頁）：

    路徑子頁關鍵參數
    藍牙/USB TNC裝置 → TNC 裝置與參數初始化字串、序列埠線速、KISS 參數（txDelay 300ms、txTail 50ms、P=63、時隙 100ms、幀長 330B）、中繼路徑 WIDE1-1,WIDE2-1
    音訊（音效卡）裝置 → 音訊（音效卡 TNC）取樣率 22050、鮑率 1200、標號 1200Hz / 空號 2200Hz、發射電平、CSMA 等待 3000ms
    Kenwood 航點裝置 → PKWDWPL 裝置唯讀鏈路；嚴格校驗和預設關（不符只標註不丟棄）
    Icom 電台直連裝置 → Icom 電台設定WLAN/LAN 遙控、使用者名稱與密碼、電台 IP、CI-V 位址（預設 0xA4）、對應頻段模式設為 FM-D
    1. 綁定裝置：子頁裡點「掃描裝置」（藍牙已配對 + USB 序列埠），選中後綁定。
    2. TNC「能收不能發」：先點「立即送出初始化字串」—— 很多模組上電停在命令模式，要收到 KISS ON 才進 KISS；再核對序列埠線速（USB 序列埠與電臺資料埠必須同速：9600/19200/38400/57600/115200；藍牙 SPP 無鮑率概念）。
    3. 音訊「對方解不出」：看出去的發射電平 —— 峰值太低或削波都解不出；用音訊線（耳機孔 → 電臺資料/麥克風孔），別用喇叭對著麥克風。
    4. 想只收不發：關掉「允許發射 / 允許射頻信標」—— 只聽信標最省心，也避免誤觸 PTT。
    5. Icom 直連：電台開啟 WLAN / LAN 遠端控制並設定 Network User 使用者名稱與密碼；手機/電腦與電台在同一區域網路，子頁中填入電台 IP、埠、帳號密碼與 CI-V 位址；將電台對應頻段模式設為 FM-D。
    ⚠️

    射頻發射需照證操作，請遵守當地法規；允許射頻信標預設關，打開前確認你的執照與本地規則允許。

    閘道 iGate#

    iGate 把射頻收到的封包轉送 APRS-IS（自動加 qAr/qAR 與你的呼號標識來路）。 入口在 設定 → 裝置 → 網關（iGate）。

    1. 先滿足條件：同時勾選 APRS-IS + 一條射頻來源（TNC 或音訊），缺哪個介面會直接告訴你。
    2. 打開 啟用網關 —— 預設只做 RF → IS（把聽到的送上網際網路）。
    3. 按需打開 雙向網關：它會在射頻上真實發射，但只轉「發給最近在射頻上聽到過的臺站」的點對點訊息；位置/天氣等廣播不轉，避免佔滿通道。
    🔁

    環路防護（自動，無需設定）：封包帶 TCPIP* 或已有 q 構造的（本來就是網際網路來的） 絕不回送；同一幀 30 秒內只注入一次。分節裡的計數（射頻收到 / 已轉遞 / 重複丟棄 / 環路拒收） 就是這四道閘的即時讀數。

    鏈路自檢與排錯順序#

    出問題時按這個順序查，一層一層來，別跳：

    1. 鏈路狀態卡（首頁頂部）：連線是否成立、收發計數是否在漲、伺服器回傳什麼。
    2. 鏈路自檢（裝置頁）：TNC 協定回路 + AFSK 調變解調回路，一鍵分層定位；TNC 側另有初始化字串與發射自檢（寫一幀狀態封包，不含座標，不會在 aprs.fi 上移動你的位置）。
    3. 封包頁：封包到底有沒有進來。能收到但不上圖 = 篩選或座標問題（見 臺站與篩選）。
    4. 閘道計數不漲：按介面提示逐條排除 —— 「射頻收到 = 0」代表封包根本沒進來，先查電臺音量/靜噪/天線。
    ✅

    回報時最有效的證據：封包頁的原始封包 + 鏈路日誌，附上它們定位最快。
