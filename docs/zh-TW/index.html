1.5.8 → 2.0 · 322 次更新

TOUCH SKY2.0 更新公告 · What's New

從純網路到射頻，從「看見」到「抵達」——這是 2.0 這一整條路的全部腳印。

APRSLocus 2.0 已於 9 月 25 日 22:00 正式發布，可在 GitHub Releases 下載最新版。

親愛的 APRSLocus 同行者：

1.5.8 之後，我們寫下了 322 次更新。這不是數字，是一條從「網路裡的一個光點」走到「天空中一聲回應」的路。以下是這一整條路的全部腳印。

一、介面 · 全新 UI 2.0：以地圖為底層的版面，地圖常駐整屏、其餘內容放進可拖曳面板，顯示設定裡可切回 1.0；底部懸浮膠囊導覽（滑動指示膠囊）＋右上懸浮膠囊（天氣 / 連線 / 定位）；把手加大到 44px 且整頁可拖；橫向在手機 / 平板 / 桌面三端統一為左欄 + 地圖；移除頂部搜尋框、返回鍵回到地圖、補回天氣與一鍵連線；16 個頁面新增「首次進入小提示卡」。

二、材質與主題：新增霧面玻璃（Acrylic）與雲母（Mica）材質，另有「滿血霧面」檔；主題的顏色 / 圖示 / 文字可自訂，支援背景圖與匯出 JSON（可帶圖）；更多權杖、介面鬆緊與字型、分頁籤強調色；備份與還原把設定與資料匯出成一個 JSON。

三、地圖 · 沉浸地圖：多圖源（高德 / 衛星 / 向量免 Key / Carto / OSM / OpenTopo / Esri）；新增沉浸地圖頁（導航風格，左側附近台站）；台站篩選可套用到地圖；離線地圖按區域下載；移除聚合；歷史軌跡回放（點進某天，動畫重播）。

四、台站與識別：接入 aprs.org 官方裝置庫，自動識別廠商 / 型號 / 類別；內建 37 個符號表、3571 個標準圖示；台站操作選單（收藏 / 複製呼號 / 刪除）與 APRS.tv 查詢；APRSlocus 平台識別（不再一律歸為手機 App）；打點演算法重做（舊幀、重複幀、錯包與模糊位置都不再騙人）。

五、訊息與翻譯：單聊群聊統一會話 + ACK 確認；群聊重構（建群 / 邀請 / 成員 / 離開，no-ack 廣播）；聊天翻譯介面從 4 家擴到 7 家，預設自動、預設走免費免金鑰介面；支援雙向翻譯、對照顯示、傳送前翻譯、語言自動識別與記憶。

六、連線與射頻：新增藍牙 TNC（完整 KISS，真正修好「能收不能發」）與音效卡 TNC（AFSK 1200，手機 + 一條音源線即 TNC）；新增 PKWDWPL（Kenwood 航點，唯讀）與閘道（iGate）；多資料來源可同時接收、發射來源單獨指定；內建鏈路自檢；修「TNC 與 PKWDWPL 同裝置瓜分資料」與「音訊發射對方解不出」。

七、定位與信標：iOS 原生定位、macOS 改原生定位；網路粗定位不再自動上報；自身定位靜止防抖；智慧信標支援「按轉彎」（先分清真轉彎與 GPS 抖動）與「按距離」打點；軌跡取樣細化並標出信標點；軌跡與資料包上限可設定。

八、天氣 · 傳播 · 建議：天氣面板（即時 + 高低溫 + 體感 + 濕度 / 氣壓 / 露點 / 風向 / 能見度 / 雲量）；業餘無線電建議按「安全警示 > 注意 > 通聯機會 > 操作提示」分級，含灰線、雨衰、結冰駐波、大氣波導；短波 / 電離層傳播逐波段日 / 夜條件，6m 單獨預測。

九、桌面小工具（Android）：天氣 + 業餘無線電提示（4 檔尺寸自適應）、短波傳播小工具、系統狀態小工具；真實圖示與圖形 logo；支援縮放與暗黑模式；新增設計預覽工具。

十、資料 · 匯出 · 備份：ADIF 匯出（頻率可自訂、匯出選項可選）；修匯出路徑與檔名；資料包主控台（原始 / 解析、手動注入、分類篩選）；新增台站面板內的統計檢視。

十一、裝置整合：Garmin App 分享短鏈（gar.mn）與 LiveTrack；藍牙心率帶（BLE 0x180D）心率隨信標上報；裝置頁新增「其他資料來源」。

十二、多語言與在地化：介面語言增至 6 種（簡體 / 繁體 / English / 日本語 / Indonesia / Español）；多批中文硬編碼清理；榮譽牆與贊助名單多語言化。

十三、社群 · 榮譽 · 公告：榮譽牆展示每枚徽章的取得條件，含「開發人員」「FIRST FIX · 至高榮譽」「早期成員」；贊助牆補齊遺漏；應用內公告橫幅取自官網 Markdown。

十四、平台 · 效能 · 穩定：iOS / macOS / 桌面三端支援與橫向打磨；修「越用越卡」的 APRS-IS 重建 + socket 洩漏；霧面玻璃與動態背景效能最佳化；大量回歸測試與靜態檢查。

以及數不清的修復：關於頁卡片貼住下個區塊、底圖切換面板彈不出來、圖層面板點了沒反應、會話輸入框藏底下、「在地圖查看」不回地圖、天氣面板點空白關不掉…… 它們共同構成了從 1.5.8 到 2.0 的 322 次更新。

它能幹什麼

位置追蹤、信標上報、消息收發、群聊……都是 APRS 裡常用的那套，儘量做得順手一些。

實時地圖追蹤

高德瓦片 / 高德衛星 / 矢量 / Carto（淺色·深色·航行者）/ OSM（標準·人道）/ OpenTopo / Esri 十多種底圖可切。一臺站一個標記（v1.6.149 起去掉聚合），也能看軌跡回放，低縮放密度看熱力圖。

  • GCJ-02 / WGS-84
  • 熱力圖
  • 軌跡顯示

位置信標

一鍵上報位置，按 APRS 1.0 標準格式發送，自動帶上高度、速度、航向和電量，上報間隔可調。

  • 標準格式
  • 自動附帶信息
  • 演示模式

消息通信

單聊、群聊統一在會話列表裡，帶 ACK 確認。支持群聊邀請、成員管理、未讀角標，中文消息也沒問題。

  • ACK 確認
  • 群聊管理
  • 中文兼容

臺站識別與篩選

接入 aprs.org 官方設備庫，從報文目的呼號識別臺站所用設備（廠商 + 型號 + 車臺 / 手臺 / 跟蹤器 / App / 網關…）。列表可篩狀態、類型、設備類別與具體型號；詳情頁可跳 QRZ 呼號庫與 aprs.fi 看軌跡。

  • 官方設備識別
  • 類別 / 型號篩選
  • QRZ / aprs.fi

數據包與日誌

原始報文用等寬字體展示，長按可複製；解析結果按位置 / 消息 / 氣象 / 狀態分類。內置分級日誌方便排查問題。

  • 原始報文
  • 類型篩選
  • 調試日誌

連接與後臺

自動連 APRS-IS 公共伺服器，TCP / WebSocket 都支持，斷線按 8 → 16 → 32 → 60 秒漸進重連。Android 用前臺服務保持在線。

  • 自動重連
  • 前臺服務
  • 系統通知

自動更新

應用內檢查更新，GitHub / GitCode 兩個渠道可切，按平臺分流下載，也能裝歷史版本。

  • 雙渠道
  • 按平臺分流
  • 歷史版本

個性化體驗

簡體中文 / 繁體中文 / English / 日本語 / Indonesia / Español 可切換，支持深色模式和自定義主題色，界面可縮放 85% ~ 130%。首次啟動有六步引導。

  • 六種語言
  • 深色模式
  • OOBE 引導

四種資料來源

網際網路（APRS-IS）、藍牙 / 串列埠 TNC（KISS）、音效卡音訊 AFSK 1200（Bell 202 軟 TNC），以及讀取 Kenwood 電台輸出的 $PKWDWPL 航點語句（唯讀、不發射）。數條鏈路可以同時收報文，發射來源單獨指定一條。

  • APRS-IS
  • TNC
  • 音訊
  • PKWDWPL

閘道（iGate）

把射頻收到的報文轉到 APRS-IS，自動帶 qAr / qAR 來路標識；具備環路防護（含 TCPIP* 或已有 q 構造的報文絕不送回），同一幀 30 秒內只注入一次。可選雙向模式會把網路側發給「剛在射頻上聽到過」的台站的訊息送到射頻。

  • RF→IS
  • 防環
  • 去重

雙向聊天翻譯

內建多引擎翻譯，預設走免費介面、無需任何金鑰。收到的和發出的訊息都能譯，可對照原文，也能在發送前先把自己的輸入譯成對方的語言。

  • 免金鑰
  • 對照翻譯
  • 發送前翻譯

沉浸地圖（導航風格）

專為「邊開車邊看」設計的導航風格頁面：大字號方向 / 距離 / 速度，左側「附近台站」面板，目標台站居中，Android 與 Windows 都能用。

  • 導航風格
  • 附近台站
  • 大字號

天氣 · 統計 · 榮譽

天氣面板（動態背景跟即時天氣強度變化）、台站統計面板（最近上報 / 最遠距離 / 報文速率），以及榮譽牆。

  • 天氣面板
  • 統計面板
  • 榮譽牆

資料匯出

一鍵匯出 ADIF —— 業餘無線電通用的日誌交換格式，頻率可自訂，匯出後可直接匯入其它日誌軟體。

  • ADIF
  • 頻率自訂

桌面小組件

Android 桌面小組件：天氣（4 種自適應尺寸）、短波傳播、系統狀態三套；小組件不自己連線，由應用單向推送快照，省電可控。

  • Android
  • 4 種自適應
  • 不自行連線

短波與電離層傳播

短波面板與獨立元件：SFI / Kp / A 指數、黑子、X 射線、太陽風，四個波段對的「日 / 夜」條件一眼看清；資料來自 hamqsl.com（N0NBH），30 分鐘快取。

  • SFI / Kp / A
  • 日 · 夜
  • 30 分鐘快取

離線地圖

把當前視圖整片瓦片下載到本機（斷點續傳、單區域上限 20 萬張），斷網、無訊號也能看；四級降級保證地圖始終可看可點。

  • 按視圖下載
  • 斷點續傳
  • 四級降級

主題與備份

主題不只是換色：顏色、圖示、文字、背景圖都能改（17 個顏色權杖），可匯出成 JSON 分享；設定與資料可整體備份，換機一鍵匯入。

  • 17 色權杖
  • JSON 分享
  • 一鍵備份

更新日誌

近期重點版本的主要變化（中間數十個以修復為主的版本已合併，完整記錄見 GitHub Releases）。

v2.0.2 2026-09-26
**新增百度地圖 / 百度衛星圖源**：百度不是 Web Mercator（BD-09 座標 + 自有投影、圖磚 y 軸朝北），為此把「依圖源切換投影」做到全鏈路 —— 渲染、標記 / 軌跡、沉浸地圖、追蹤、歷史回放、離線下載共用同一套投影，標記與圖磚不再錯開。
**新增「純網路」定位模式**：只用基地台 / Wi-Fi（不註冊 GPS），適合沒有 GPS 的裝置，也用於極端省電；自動上報使用專用固定間隔（預設 300 秒、可調），不必再開強制開關，也不走智慧信標（網路沒有可靠速度）。
**公告支援內嵌影片**：應用內公告改為手寫 Markdown（簡中 / 繁中 / 英文），`@video` 標記可在應用內播放（Android / iOS / macOS；Windows / Linux / Web 回退為在瀏覽器開啟）。舊版本讀到那行只會當普通文字（仍是可點連結）。
**啟動檢查新版本**：啟動後檢查一次，有新版時彈提醒（每版本只提醒一次、可稍後）。
**修**：地圖資訊窗仍顯示「點選檢視」—— 2.0.1 只改了生成的 l10n 產物、漏改 ARB 源，建置時被覆蓋，現已改到位（六語言）；Windows 建置移除與當前工具鏈不相容的 webview_windows，改走外部瀏覽器。
v2.0.0 2026-09-25
**TOUCH SKY · 2.0 正式版**：1.5.8 → 2.0 的 **322 次更新**在這一版合流 —— 全新 UI 2.0（地圖基底 + 可拖曳面板、底部膠囊導覽、橫向三端統一）、磨砂玻璃與雲母材質、沉浸地圖與多圖源、離線地圖與軌跡回放、官方裝置庫辨識、群組聊天與 7 家翻譯、藍牙 TNC 與音效卡 TNC、iGate 與 PKWDWPL、iOS / macOS 原生定位、按轉彎與按距離的智慧信標、天氣與短波傳播建議、Android 桌面小工具、ADIF 匯出與封包主控台、Garmin 分享與藍牙心率帶、6 種介面語言。
v1.6.173 2026-09-24
**佳明頁補齊了「自動填入 / 確定按鈕 / 狀態顯示」**（使用者實測回饋）：① 連結框原來只在頁面初始化時讀一次，分享進來時頁面已經開著就**不會自動填入** —— 現在跟隨狀態同步，並顯示「已自動填入分享連結」；② 原來只有一個含義模糊的開關（標籤寫著「追蹤中」是狀態不是動作）—— 現在是明確的 **[開始追蹤] / [停止追蹤]** 按鈕；③ 新增狀態卡：未開啟追蹤 / 追蹤中（含已轉發點數與最後更新時間）/ 抓取失敗（含原因），連結框下面還會即時顯示「連結有效」。分享到達的提示也從 4 秒延長到 8 秒，不容易錯過
v1.6.172 2026-09-24

常見問題

從 Passcode 到後臺耗電，能想到的問題都寫在這裡了。還有 23 題按主題分組的完整版，見 幫助中心。

為什麼收不到消息 / 無法收發消息？

絕大多數情況是 Passcode 未驗證。密碼填 -1 只能連接，不能正常收發消息。請到 APRS Passcode 查詢 生成自己的 Passcode 並填入「連接設置」。登錄後若伺服器返回 unverified，主頁頂部會出現黃色警告橫幅，點擊「去設置」即可直達修改。

Passcode 該怎麼設置？

在引導第 6 步或「設置 → 連接」中，用你的完整呼號（含 SSID 後綴，如 BG7LZQ-3）查詢生成 Passcode 後填入即可。

連接失敗 / 頻繁掉線？

應用內置漸進式重連（8 → 16 → 32 → 60 秒）。若持續失敗，請檢查網絡、確認伺服器地址（默認 rotate.aprs2.net:14580）與埠是否被攔截，或在「連接設置」中更換伺服器後點擊「重新連接」。

手機上收不到周邊臺站？

檢查「接收篩選」是否勾選了目標國家 / 地區，並確認接收範圍（經緯度 + 半徑）覆蓋你的位置。默認只接收中國（B 開頭）臺站。

後臺定位會一直耗電嗎？

Android 端使用前臺服務持續定位以保持 APRS 在線，可在「定位 / 信標」設置中調整上報間隔，或關閉信標上報、按需手動上報來降低耗電。通知欄可一鍵「退出」應用。

Windows 上地圖顯示異常？

建議在「顯示 → 地圖類型」中切換為矢量地圖（無需 API Key，兼容性最好），或使用 Carto / OSM / Esri 等國際圖源。

覆蓋安裝提示籤名衝突 / 版本降級？

自 1.5.2 起 Android 使用正式 release 籤名，CI 與本地籤名一致，直接覆蓋安裝即可。若從更老版本升級，請卸載後重裝。
