    先用这三个入口#

    1. 链路状态卡（主页顶部）——连接是否成立、收发计数、服务器返回值。 返回 unverified = Passcode 问题（去填）。
    2. 链路自检（设备页）—— TNC 协议回路、AFSK 调制解调回路，一键分层定位； TNC 另有初始化串与发射自检（状态包，不含坐标）。
    3. 数据包页—— 原始报文到底有没有进来。能收到但不上图 = 筛选/坐标问题， 回台站与筛选；一条都没有 = 链路问题，回第 1、2 步。

    症状 → 原因 → 动作#

    症状最可能的原因动作
    黄色「未验证」横幅Passcode 空 / 错设置 → 连接 → 填正确 Passcode → 保存并应用
    连不上服务器网络 / 服务器地址 / 端口核对 rotate.aprs2.net:14580；断线会自动 8→16→32→60s 重连，等一轮
    数据包页一条都没有没勾数据来源 / 范围过滤太窄设置 → 连接：勾 APRS-IS；范围半径调大 → 保存并应用
    收到但地图上看不到列表筛选挡住了台站页点「清除筛选」；核对状态/类型筛选
    自己位置不显示/乱跳没定位权限 / 用了网络粗定位给定位权限；设置 → 定位上报 → 定位模式选纯 GPS
    TNC 能收不能发停在命令模式 / 线速不匹配发送初始化串（KISS ON）；核对 9600~115200 与电台一致
    音频对方解不出发射电平过低或削顶 / 用错线调整发射电平；耳机口 → 电台数据/话筒口，勿用扬声器对麦克风
    消息发出去没反应超 67 字符 / 512 字节；对方不在线缩短内容；看气泡状态，超时即失败
    群聊收不到射频模式不支持群广播；Passcode 未验证切到 APRS-IS 发；先修 Passcode
    网关计数不涨缺一个来源（APRS-IS 或射频）/ 射频收到=0按界面提示补齐来源；射频收到=0 先查电台音量/静噪/天线
    桌面组件空白组件没有数据（应用没打开过）打开一次应用刷新
    离线地图断网打不开没下载该屏 / 未开仅离线移到目标屏下载；开「仅使用离线瓦片」
