    能力矩阵 Web 版的取舍

    能力矩阵#

    能力AndroidWindows
    APRS-IS 收发✓✓
    后台持续定位（前台服务）✓—（桌面无前台服务概念）
    蓝牙 TNC✓（需蓝牙权限）—（用 USB 串口 COM 口）
    USB 串口（OTG）✓✓（COM 口独占，别被别的软件占着）
    音频 AFSK✓（需录音权限；发射时拉满音量并暂停麦克风）✓
    离线地图下载✓✓
    桌面小组件✓（3 套）—（Android 独有）
    WAV 文件模式所有平台可用：离线解码录音，或把报文导出成音频

    Web 版的取舍#

    ⚠️

    Web 版是「能看、能连」的轻量形态：

    • 不提供离线地图下载（浏览器没有稳定可写目录）；
    • 备份走剪贴板（复制 / 粘贴），不落文件；
    • 实时音频在不支持的平台会提示，仍可用 WAV 模式（上传录音离线解码）；
    • 无桌面小组件、无后台持续定位。
