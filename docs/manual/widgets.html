    三套桌面组件#

    Android 主屏长按 → 小组件 → 找 APRSlocus：

    组件内容
    天气图标、温度、现象、今日高低温 + 指标格 + 火腿建议；按主屏空间自动切 4 档布局（主档 / 竖长 / 紧凑 / 单行）
    短波各波段「日 → 夜」条件色带，一眼看出现在该用哪一段
    系统状态链路、定位与计数的实时快照
    1. 添加组件 → 先打开一次应用（组件要应用推数据）。
    2. 升级后若显示空白：再打开一次应用即可刷新。
    📲

    组件不自己联网：应用把已计算、已本地化的快照单向推给原生渲染 —— 天气接口密钥只在应用侧，不会外泄到组件。

    短波传播面板#

    • 数据来源：hamqsl.com（N0NBH 整理，业余界事实标准）；源站约每小时更新，应用缓存 30 分钟。
    • 看什么：SFI / Kp / A 指数、黑子、X 射线、太阳风；四个波段对的日 / 夜条件一目了然，另有 6m 预测。
    • 怎么看：绿色好、黄色凑合、红色差 —— 先挑「日」或「夜」里颜色最好的那一段。
    诚实

    hamqsl 的条件是全球/区域平均，不是你所在地的实测值 —— 出门前请结合本地时间、天线与噪声底再判断。
