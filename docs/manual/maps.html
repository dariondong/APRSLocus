    选图源 坐标不漂：WGS-84 ↔ GCJ-02 下载离线地图 界面风格与主题

    选图源#

    入口：地图页 → 图源/地图菜单。按用途选：

    图源什么时候用
    高德 / 高德卫星国内定位无缝对齐（GCJ-02）
    矢量地图客户端实时渲染、缩放清晰、无需 API Key、WGS-84 —— 首选
    Carto 浅色 / 深色 / 航行者在线瓦片，深色页配深色图
    OSM 标准 / 人道通用底图
    OpenTopo 地形等高线与地形
    Esri 街道 / 影像街道 / 卫星影像
    ✅

    验证：切图源后你的标记位置不应跳动超过 500 米 —— 做不到就说明纠偏没生效，见下一节。

    坐标不漂：WGS-84 ↔ GCJ-02#

    🗺️

    APRS 全球用 WGS-84；国内图源（高德）用 GCJ-02。 应用内置双向转换：国内图源按 GCJ-02 对齐、切回国际图源还原 —— 所以切换图源不会把你的位置挪出 500 米， 台站、轨迹、我的位置一起对齐。

    • 手动定位的坐标按 WGS-84 输入 —— 从地图选点时内部会自动换算。
    • 发现某个图源整体偏移：先确认它属于哪类坐标系，再看是不是用了「仅离线瓦片」混了旧缓存。

    下载离线地图#

    1. 先把地图平移缩放到要覆盖的那一屏 —— 下载范围 = 当前所见（不是选框）。
    2. 设置 → 显示 → 离线地图（或地图菜单里的离线入口）→ 开始下载。
    3. 支持断点续传；单区域上限 20 万张瓦片（约 3 GB）。
    4. 下完开 仅使用离线瓦片：一个网络请求都不发，完全离线可用。
    ⚠️

    Web 版不提供下载（浏览器没有稳定可写目录）—— 需要离线图请用 Android / Windows。

    界面风格与主题#

    • UI 2.0：以地图为基底的新布局（默认），「显示设置」里可随时切回经典布局；材质在磨砂玻璃与云母之间切换。
    • 深色模式：设置 → 显示 → 深色模式（跟随系统 / 强制开 / 强制关）。
    • 主题（设置 → 主题）：17 个颜色令牌、图标、文字、背景图都能改，导出 JSON 可分享；界面缩放 85% ~ 130%。
    • 天气组件开关也在这一页 —— 关掉后主页天气卡不再请求数据。
