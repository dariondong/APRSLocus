    六条链路：两条在互联网，四条接电台#

    入口 设置 → 服务器。这一页只摆两台互联网服务器，一台一张卡，卡上有自己的开关，点进去才是它的地址与口令。

    链路走什么收发
    APRS-IS互联网 TCP，地址自己填✓✓
    APRSNETCN SERVER同一套协议的国内服务器，地址自己填✓✓
    TNC蓝牙 SPP 或 USB 串口，KISS 协议✓✓
    音频耳机口接电台，AFSK 1200（Bell 202）✓✓
    WLAN 电台直连Wi-Fi 直连 Icom 电台（IC-705 / IC-9700 等）✓✓
    PKWDWPL读 Kenwood 输出的航点语句✓✗ 只读

    发射要分两行选。「位置与状态报文」可以同时勾几条链路，两条互联网链路一起发也不会撞包。「消息」只勾一条，它只认自己那条链路，没连上就发不出去。

    📡

    接收范围默认 300 km（最小 10 km），规则是 r/纬度/经度/半径。改完要点 「保存并应用过滤」 才生效。

    接上 APRS-IS#

    两条互联网链路是平的，APRS-IS 不特殊。它的参数都在自己的子页里，与 APRSNETCN 那张卡各管各的。

    1. 设置 → 服务器 → APRS-IS 服务器，填服务器地址与端口 14580。地址留空就连不上，软件不预置服务器。
    2. 填 Passcode：用完整呼号生成，见 快速上手。留空或 -1 只能收，消息发不出去。
    3. 打开卡片顶部的开关。主页本来连着的话这一条会自己连上，没连着就回主页点连接。
    4. 看链路状态卡：显示已连接，收包计数开始涨。
    • 地址、端口和 Passcode 改了自动保存，不用再点按钮。
    • 断线自己重连：8 → 16 → 32 → 60 秒逐步退回。
    • 服务器回 unverified 就是 Passcode 没通过，回第 2 步。
    • 要走自建中转就填 WebSocket URL，留空走标准 TCP。

    第二条链路：APRSNETCN#

    APRSNETCN 与 APRS-IS 并列。它跑同一套 APRS-IS 协议，服务器在国内，地址同样要自己填。收发都能走它，只连它一条也能用。

    1. 设置 → 服务器 → APRSNETCN SERVER，填地址与端口。
    2. 填 Passcode。服务器给过账号与口令的，把这两格也填上。
    3. 打开开关，看卡片里的链路状态。
    4. 要 24 小时台站就在卡片下面点同步，收下来的台站与 APRS-IS 的并在一起。
    • 登录结果单独一行。口令错了链路会连上又断开，原因只写在这里。
    • 两台同时在线时同一条报文只记一次，两边各收一份也不会重复计数。
    • 换了地址或口令后点卡片里的重连，新参数才生效。

    云同步：消息与轨迹存到服务器#

    云同步把消息与历史轨迹存到服务器上。换一台设备，登录同一个账号就能拉回来。它挂在 APRSNETCN 那一页，整块可以关掉。

    1. 设置 → 服务器 → APRSNETCN SERVER，往下就是云同步那几张卡，先填账号与口令。
    2. 点登录。登录后卡片换成账号与云端的三行数字。
    3. 同步方式选 关闭 / 手动 / 自动，自动那档可以选 5、15 或 60 分钟一轮。
    4. 把想同步的那一类打开：消息、历史轨迹，各一个开关。
    5. 要马上同步点「立即同步」，要清掉云端那份点「清空云端数据」。
    • 账号就是服务器接入名单里那一条，与 APRSNETCN 链路页填的是同一个。
    • 地址跟着 APRSNETCN 那条链路走，这里没有第二个地址。换服务器要重新登录，旧地址上的数据不搬。
    • 同步的是消息与按天的历史轨迹。应用设置与主题在「备份与恢复」页。
    • 两台设备同一天都记了轨迹，读回来是一条线。时间差 3 秒内、距离 50 米内算同一个点。
    • 「登录的设备」里是登录过这台服务器的设备，本机带标记。移除一台，它下次同步要重新登录。
    • 连接是明文 HTTP，口令与内容不加密。口令登录后从本机清掉，令牌留在本机，退出登录即丢弃。
    • 到「设置 → 功能」可以把云同步整块关掉。关掉之后不再联网，两条链路照旧。

    外接 GPS 模块#

    外接 GPS 是一台蓝牙 NMEA 模块，接上以后由它供位置。它的定位比手机稳，也省手机的电。它不是一条 APRS 链路，只负责告诉应用你在哪。

    1. 设置 → 设备 → 外接 GPS。
    2. 点扫描设备，选中模块后绑定。模块走蓝牙 SPP，要先在系统里配对。
    3. 连接成功后看「当前定位」：纬度、经度、卫星数和精度都在这一块。
    4. 要卫星数随信标发出去，去 设置 → 定位上报 打开「卫星数」。
    • 模块在位时手机定位自动待机。模块掉线会切回手机 GPS，日志里写一句。
    • 「严格校验和」默认开，语句校验不符直接丢弃。排查兼容性问题时可以关掉，改成只标注。
    • 语句计数在涨但没有定位，多数是室内收不到星。语句不涨就查蓝牙这一层。

    接电台：TNC / 音频 / PKWDWPL / Icom#

    四条射频路径的入口都在 设置 → 设备（设备总览页列出当前链路与四个子页）：

    路径子页关键参数
    蓝牙/USB TNC设备 → TNC 设备与参数初始化串、串口线速、KISS 参数（txDelay 300ms、txTail 50ms、P=63、时隙 100ms、帧长 330B）、中继路径 WIDE1-1,WIDE2-1
    音频（声卡）设备 → 音频（声卡 TNC）采样率 22050、比特率 1200、标号 1200Hz / 空号 2200Hz、发射电平、CSMA 等待 3000ms
    Kenwood 航点设备 → PKWDWPL 设备只读链路；严格校验和默认关（不符只标注不丢弃）
    Icom 电台直连设备 → Icom 电台设置WLAN/LAN 遥控、用户名与密码、电台 IP、CI-V 地址（默认 0xA4）、对应频段模式设为 FM-D
    1. 绑定设备：子页里点「扫描设备」（蓝牙已配对 + USB 串口），选中后绑定。
    2. TNC「能收不能发」：先点「立即发送初始化串」—— 很多模块上电停在命令模式，要收到 KISS ON 才进 KISS；再核对串口线速（USB 串口与电台数据口必须同速：9600/19200/38400/57600/115200；蓝牙 SPP 无波特率概念）。
    3. 音频「对方解不出」：看出去的发射电平 —— 峰值太低或削顶都解不出；用音频线（耳机口 → 电台数据/话筒口），别用扬声器对着麦克风。
    4. 想只收不发：关掉「允许发射 / 允许射频信标」—— 只听信标最省心，也避免误触 PTT。
    5. Icom 直连：电台开启 WLAN / LAN 远程控制并设置 Network User 用户名与密码；手机/电脑与电台在同一局域网，子页中填入电台 IP、端口、账号密码与 CI-V 地址；将电台对应频段模式设为 FM-D。
    ⚠️

    射频发射需持照操作，请遵守当地法规；允许射频信标默认关，打开前确认你的执照与本地规则允许。

    网关 iGate#

    iGate 把射频收到的报文转送 APRS-IS（自动加 qAr/qAR 与你的呼号标识来路）。 入口在 设置 → 设备 → 网关（iGate）。

    1. 先满足条件：同时勾选 APRS-IS + 一条射频来源（TNC 或音频），缺哪个界面会直接告诉你。
    2. 打开 启用网关 —— 默认只做 RF → IS（把听到的送上互联网）。
    3. 按需打开 双向网关：它会在射频上真实发射，但只转「发给最近在射频上听到过的台站」的点对点消息；位置/天气等广播不转，避免占满信道。
    🔁

    环路防护（自动，无需配置）：报文带 TCPIP* 或已有 q 构造的（本来就是互联网来的） 绝不回送；同一帧 30 秒内只注入一次。分节里的计数（射频收到 / 已转递 / 重复丢弃 / 环路拒收） 就是这四道闸的实时读数。

    链路自检与排错顺序#

    出问题时按这个顺序查，一层一层来，别跳：

    1. 链路状态卡（主页顶部）：连接是否成立、收发计数是否在涨、服务器返回什么。
    2. 链路自检（设备页）：TNC 协议回路 + AFSK 调制解调回路，一键分层定位；TNC 侧另有初始化串与发射自检（写一帧状态包，不含坐标，不会在 aprs.fi 上挪动你的位置）。
    3. 数据包页：报文到底有没有进来。能收到但不上图 = 筛选或坐标问题（见 台站与筛选）。
    4. 网关计数不涨：按界面提示逐条排除 —— 「射频收到 = 0」说明报文根本没进来，先查电台音量/静噪/天线。
    ✅

    反馈时最有效的证据：数据包页的原始报文 + 链路日志，附上它们定位最快。
