    收什么：范围与接收偏好#

    两层过滤都在 设置 → 连接，决定「报文到不到得了你」：

    1. 接收范围过滤：r/纬度/经度/半径，默认 300 km（最小 10 km）。 勾「过滤中心跟随我的位置」就以你为圆心；改完点 保存并应用。
    2. 接收呼号筛选（接收偏好）：按国家/地区勾选；另有总开关决定是否也收未勾选国家的台站。 还可以精确到某个呼号 —— 范围之外也收指定呼号。
    3. 向导里选的「接收地区」就是这里的国家/地区勾选；不勾 = 全收。
    🧭

    「收不到」先查这两处，再查链路 —— 顺序反了会白折腾： 范围 300 km 之外的台站，链路再通也到不了你。

    看什么：列表筛选#

    台站页签上再做一层展示筛选（不影响接收）：

    • 状态：在线 / 移动 / 静止 —— 「在线判定时长」在 设置 → 连接 → 数据上限（默认 5 分钟）。
    • 类型：APRS 类型（车载/固定/中继/气象）、软件（APRSLocus）、设备类别与具体型号。
    • 收藏：标星的台站单独一档。
    • 搜索：呼号 / 类型 / 备注 / 网格 —— 台站几万条也不卡（内存上限默认 10 万条，可调）。
    ✅

    验证：列表顶部应显示当前筛选的命中数；点「清除筛选」应回到全量。 若全量也没有目标台站，那是没收到（回到上一节）而不是没显示。

    台站详情与设备识别#

    • 官方设备库：接入 aprs.org 的 aprsorg/aprs-deviceid（tocall），按报文目的呼号识别 厂商 + 型号 + 设备类别（车台/手台/追踪器/App/iGate/中继/气象站…）；内置快照 + 联网自动更新。
    • 同款 APRSlocus 台站自动标记，能看到版本、电量等专属信息；FMO 台站自动识别。
    • 详情页可跳转：QRZ 呼号库、aprs.fi 看轨迹、APRS.tv。
    • 符号：37 个官方符号表、3571 个标准图标 —— 官方 PNG 优先、Material 图标兜底。
    • 轨迹回放：详情里可回放该台站的轨迹（数据在本地历史里）。
