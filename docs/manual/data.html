导出 ADIF 备份与恢复 历史轨迹与回放

导出 ADIF

  1. 入口：设置 → 导出 ADIF。
  2. 频率可自定义（ADIF 是业余无线电通用日志交换格式）。
  3. 导出的文件可直接导入其它日志软件。
✅

验证：导出后用任意日志软件打开，能看到呼号、时间、模式字段即成功。

备份与恢复

  1. 导出（设置 → 备份与恢复 → 导出备份）：设置配置（电台、信标、地图、筛选、数据来源、服务器等） 与本地数据进一个 JSON；可勾选是否包含图片。
  2. 导入：选择备份文件（或从剪贴板粘贴）→ 导入后重启应用生效。
  3. 换机 / 重装的顺序：装应用 → 导入 → 重启 → 核对「设置 → 连接」的服务器与 Passcode。
🔐

白名单导入：只认该分组白名单内的键 —— 来路不明的 JSON 改不了内部设置； 更高版本的备份会被拒绝并提示先升级。备份文件含呼号、服务器口令与 API 密钥，请妥善保管。

平台差异：Android 用系统文件选择器（下载目录）；Windows 存 Documents；Web 版走剪贴板。 读取上限 32 MB。

历史轨迹与回放

  1. 入口：设置 → 历史轨迹。
  2. 按天落盘：tracklog/YYYY-MM-DD.json，记录经纬度、速度、航向、海拔、精度 —— 退出重进还在。
  3. 每天一屏：总里程、平均与最高速度、移动时长、轨迹点数；可按天删除或一键清空。 移动时长只累计确实在动的段 —— 中途停车吃饭的两小时不算开车。
  4. 点进某天可回放：底图与主地图同一套（同缓存、同坐标纠偏）；轨迹随播放生长、可拖进度、 0.5× ~ 4× 倍速、可跟随视角；超过 45 秒的停顿自动快进。
🧾

它与地图上那条「我的轨迹」刻意分开：屏幕轨迹只服务本次显示，退出即失； 历史轨迹是留档，可导出、可回放。
