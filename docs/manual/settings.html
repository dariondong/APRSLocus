    TNC 初始化串

    连接后逐行发送（等价 APRSdroid 的 kiss.init）

    ℹ️

    若 TNC「能收不能发」，先在这里试：很多蓝牙/串口 TNC 模块上电停在命令模式，必须先收到 KISS ON、RESTART 等指令才进入 KISS 转发状态。每行一条命令（发送时自动补 CRLF）。

    设置项控件默认值说明
    行间隔 (ms) initDelayMs输入框300每行命令之间的等待时间。模块处理命令需要时间，太短会丢命令
    串口线速 (bd) serialBaud输入框9600USB 串口线与电台数据口必须同速，否则一个字节都收不到。常见值：9600 / 19200 / 38400 / 57600 / 115200。蓝牙 SPP 没有波特率概念，绑蓝牙设备时此项不生效。

    KISS 参数

    直接下发到 TNC 的链路层参数

    设置项控件默认值说明
    连接后下发 KISS 参数 pushKissParams开关关默认关闭（与 APRSdroid 一致）。打开后连接时会把上面的参数推给 TNC，覆盖它自己的配置 —— 参数不合适可能让它一直退避而不发射，所以只在需要统一管理时打开。
    发射延时 (ms) txDelayMs输入框300KISS TXDELAY，单位 10ms。发射前留给自己 PTT 建立的时间
    发射尾音 (ms) txTailMs输入框50KISS TXTAIL，单位 10ms。某些电台需要尾部保持才能收全
    持续度 P persistence输入框63KISS PERSISTENCE，0-255。越小越礼让，共用信道时能减少碰撞
    时隙 (ms) slotTimeMs输入框100KISS SLOTTIME，单位 10ms。与持续度共同决定信道竞争节奏
    全双工 fullDuplex开关关
    信道 / KISS 端口 channel输入框0多信道 TNC 才有多端口，单信道电台保持 0
    帧长上限 (字节) maxFrame输入框330超过此长度的报文不会发出（1200bd 下 AX.25 单帧约 330 字节）
    射频中继路径 path输入框WIDE1-1,WIDE2-1射频上使用的中继，如 WIDE1-1,WIDE2-1；留空则不指定

    参数值 hardwareVal输入框0KISS SETHARDWARE (0x06)，厂商自定义；-1 表示不下发

    音频（声卡 TNC）

    用声卡收发 AFSK 1200 报文

    设置项控件默认值说明
    采样率 sampleRate输入框2205022050Hz 是声卡 TNC 常用值；设备不支持时改用 44100/48000。修改会重启采集
    比特率输入框—APRS 在 VHF 上固定 1200 bd（Bell 202），HF 才用 300
    标号频率 (Hz)输入框—Bell 202 规定标号 1200Hz、空号 2200Hz；只有 ±几 Hz 的容差，不要随意改
    空号频率 (Hz)输入框—空号音调。与标号音调一起决定 FSK 频偏（标准为 1000Hz）
    发射前导 (ms) txDelayMs输入框300发射前导时长：给对端解调器锁定时间、给电台 PTT 建立时间

    发射前等待信道空闲 (ms) csmaWaitMs输入框3000检测到信道占用时最多等待多久；0 = 不等待直接发射

    帧长上限 (字节) maxFrame输入框330超过此长度的报文不会发出（1200bd 下 AX.25 单帧约 330 字节）
    发射电平只读状态—发射前系统会把媒体音量拉到最大、并暂停麦克风采集；峰值太低或削顶都会让对端解不出
    自动回复 ACK autoAck开关开关闭后不回应收到的消息回执，可减少射频占用
    断开后自动重连 autoReconnect开关开
