连接与消息

为什么收不到消息 / 无法收发消息？

绝大多数情况是 Passcode 未验证。密码填 -1 只能连接，不能正常收发消息。请到 APRS Passcode 查询 生成自己的 Passcode 并填入「连接设置」；若服务器返回 unverified，主页顶部会出现黄色警告横幅，点「去设置」即可直达。

Passcode 该怎么设置？

在引导第 6 步或「设置 → 连接」中，用你的完整呼号（含 SSID 后缀，如 BG7LZQ-3）查询生成 Passcode 后填入即可。

连接失败 / 频繁掉线？

应用内置渐进式重连（8 → 16 → 32 → 60 秒）。若持续失败，请检查网络、确认服务器地址（默认 rotate.aprs2.net:14580）与端口是否被拦截，或在「连接设置」中更换服务器后点「重新连接」。

支持哪些数据来源？我该怎么选？

四条：互联网 APRS-IS、蓝牙 / 串口 TNC（KISS）、声卡音频 AFSK 1200，以及 Kenwood 电台的 $PKWDWPL（只收不发）。刚上手选 APRS-IS 即可；有电台想听射频，再加 TNC 或音频。几条链路可同时收报文，发射来源单独指定一条。

网关（iGate）是什么？需要开吗？

iGate 把你在射频上听到的报文转到 APRS-IS，让全球网络看到你附近的台站。只有「在听射频、且愿意贡献」时才需要。带环路防护（含 TCPIP* 或已有 q 构造的报文绝不回送）与 30 秒去重，默认关闭。

蓝牙 TNC 连上了，但收不到 / 发不出？

先升级到最新版：v1.6.110 修了「TNC 与 PKWDWPL 绑定同一台设备、互相瓜分接收数据」，v1.6.112 找到「能发不能收」的真正原因。升级后仍异常，用「链路自检」分层排查，并确认 Android 已授予蓝牙与定位权限。

声卡音频（AFSK）怎么接？对方解不出怎么办？

耳机 / 麦克风口接电台的 SPK / MIC，设置好 PTT。发射时应用会把媒体音量拉满并暂停麦克风，链路自检里能看到电平；对方解不出，先查电平与接线。

定位与信标

手机上收不到周边台站？

检查「接收筛选」是否勾选了目标国家 / 地区，并确认接收范围（经纬度 + 半径）覆盖你的位置。默认只接收中国（B 开头）台站。

后台定位会一直耗电吗？

Android 端使用前台服务持续定位以保持 APRS 在线，可在「定位 / 信标」设置中调整上报间隔，或关闭信标上报、按需手动上报来降低耗电。通知栏可一键「退出」应用。

站着不动时我的标记乱跳 / 轨迹有毛刺？

v1.6.146 给自身定位加了「静止防抖」；v1.6.149 再用加速度计判断「有没有在动」、低速时用指南针补航向（Android，默认开启，可在「设置 → 信标 → 定位」关）。升级到最新版即可。

历史轨迹在哪看？和地图上那条有什么区别？

「设置 → 历史轨迹」按天保存在本地，可看总里程、平均与最高速度、移动时长，退出重进还在；点某一天还能在地图上回放当天路线（可拖进度、0.5×~4× 倍速）。它与地图上那条「我的轨迹」刻意分开：那条只服务本次显示，退出即失、确认位置跳变时整条清空。

界面与地图

Windows 上地图显示异常？

建议在「显示 → 地图类型」中切换为矢量地图（无需 API Key，兼容性最好），或使用 Carto / OSM / Esri 等国际图源。

怎么换界面风格 / 切回旧布局？

「设置 → 显示」里可切 UI 2.0（以地图为基底）与经典布局，还能选磨砂玻璃 / 云母材质（v1.6.138）。主题支持颜色、图标、文字与背景图（17 个颜色令牌），可导出 JSON 分享。

台站为什么不再合并成一颗球？

v1.6.149 起去掉聚合：矢量地图与自绘地图都是一台站一个标记。低缩放时的密度交给热力图，工具列里有开关。

离线地图怎么用？断网能看吗？

「设置 → 显示 → 离线地图」把当前视图的瓦片一次下到本机（断点续传、单区域上限 20 万张），断网、无信号也能看，另有「仅离线模式」。Web 版不提供下载。

支持哪些语言？翻译要密钥吗？

界面六种语言：简体中文、繁體中文、English、日本語、Indonesia、Español。聊天翻译默认走免费接口、无需任何密钥，可双向、可对照，也能发送前先把输入译成对方的语言。

桌面小组件与短波

桌面小组件怎么添加？为什么是空的？

长按桌面 → 添加小部件 → APRSlocus，有天气、短波、系统状态三套。组件不自己联网，数据由应用单向推送 —— 装好后先打开一次应用；升级后若空白，打开应用刷新即可。

短波面板的数据准吗？多久更新？

来自 hamqsl.com（N0NBH 整理，业余界事实标准），源站约每小时更新，应用缓存 30 分钟。注意它是全球 / 区域平均，不是你所在地的实测值。

小组件能调大小吗？

天气组件四档自适应；v1.6.133 起短波与系统状态也能拖拽缩放，拉高会自动换「加高档」。

数据、备份与安装

换手机 / 重装怎么迁移？

「设置 → 备份与恢复」把设置与数据导出成一个 JSON，新设备导入即可（v1.6.123）。导入后需重启应用生效。

怎么导出通联日志？

数据导出为 ADIF —— 业余无线电通用的日志交换格式，频率可自定义，导出后可直接导入其它日志软件。

覆盖安装提示签名冲突 / 版本降级？

自 1.5.2 起 Android 使用正式 release 签名，CI 与本地签名一致，直接覆盖安装即可。若从更老版本升级，请卸载后重装。

在哪里下载？怎么更新？

GitHub Releases 与 GitCode 双渠道；应用内「检查更新」按平台分流，也能安装历史版本。本站导航「下载」直达最新版。
