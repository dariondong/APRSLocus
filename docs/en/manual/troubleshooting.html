    Start with these three#

    1. Link status card (top of the home page) — is the link up, what are the counters, what did the server return? unverified = Passcode problem (fix it here).
    2. Link self-test (device page) — TNC protocol loopback and the AFSK modulate/demodulate loop, layer by layer; the TNC side adds the init string and a TX self-test (status frame, no coordinates).
    3. Packets tab — did raw frames arrive at all? Received but never plotted = filter/coordinate, go back to Stations; nothing at all = link problem, back to steps 1–2.

    Symptom → cause → action#

    SymptomLikely causeAction
    Yellow “unverified” bannerPasscode empty or wrongSettings → Connection → correct it → Save & apply

    Packets tab is emptyno source ticked / range too narrowSettings → Connection: tick APRS-IS, raise the radius → Save & apply
    Received but not on the maplist filter hiding itStations → clear filters; re-check status/type
    My position missing or jumpingno location permission / network fixesgrant permission; Settings → Beacon → GPS only
    TNC receives, never transmitscommand mode / baud mismatchsend the init string (KISS ON); match 9600–115200 to the radio
    Audio nobody decodeslevel too low or clipped / wrong cableadjust TX level; headphone jack → radio data/mic, never speaker-to-mic
    Message sent, no replyover 67 chars / 512 bytes; peer offlineshorten it; watch the bubble — a timeout means failure
    Group messages never arriveRF mode has no group broadcast; Passcode unverifiedsend over APRS-IS; fix the Passcode first
    Gateway counters stay at zeroa source is missing / RF seen = 0tick the missing source; RF seen = 0 → radio volume, squelch, antenna
    Widget is blankno data pushed yetopen the app once to refresh
    Offline map won’t open offlinethat screen was never downloadedpan there and download; enable “offline tiles only”
