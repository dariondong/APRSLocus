Web build trade-offs

⚠️

The web build is the lightweight “view and connect” shape:

  • no offline map download (browsers have no stable writable directory);
  • backup runs through the clipboard (copy / paste), no files;
  • realtime audio warns where unsupported while WAV mode still works (upload a recording, decode offline);
  • no home-screen widgets, no continuous background positioning.
