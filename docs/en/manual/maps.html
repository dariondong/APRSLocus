Check: after switching, your marker must not jump more than 500 m — if it does, datum correction is not applied, see next.

No drift: WGS-84 ↔ GCJ-02

🗺️

APRS uses WGS-84 worldwide; Chinese sources (AMap) use GCJ-02. The app converts both ways — Chinese sources are aligned to GCJ-02 and restored when you switch back — so switching layers never moves you by 500 m; stations, tracks and your own marker move together.

  • Manual coordinates are entered as WGS-84; picking a point on the map converts internally.
  • A whole layer looks offset: check which datum it uses, then whether “offline tiles only” is serving a stale cache.

Download offline maps

  1. Pan and zoom the map to the screen you want to keep — the download area is exactly what you see (no box selection).
  2. Settings → Display → Offline map (or the offline entry in the map menu) → download.
  3. Resumable; capped at 200k tiles (~3 GB) per region.
  4. Then enable offline tiles only: zero network requests, fully offline.
⚠️

The web build offers no download (browsers have no stable writable directory) — use Android or Windows for offline maps.

Look and feel

  • UI 2.0: the map-first layout (default); Display settings switches back to the classic one at any time; material toggles between frosted glass and mica.
  • Dark mode: Settings → Display → dark mode (follow system / force on / force off).
  • Themes (Settings → Themes): 17 colour tokens, icons, text and background are editable and exportable as JSON; UI scaling runs 85–130%.
  • The weather widget switch is on the same page — off means the home weather card stops requesting data.
