What It Does

Position tracking, beacon reporting, messaging, group chat — all the APRS essentials, built to be straightforward.

Real-time Map Tracking

Six tile sources: AMap tiles, AMap satellite, AMap JS, Vector, Carto, and OSM. Stations are grouped by callsign, with trail playback support.

  • GCJ-02 / WGS-84
  • Station Clustering
  • Trail Display

Position Beacon

One-tap position reporting in standard APRS 1.0 format. Auto-includes altitude, speed, heading, and battery level. Report interval is configurable.

  • Standard Format
  • Auto Attachments
  • Demo Mode

Messaging

Private and group chat in a unified conversation list with ACK confirmation. Supports group invites, member management, unread badges, and Chinese text.

  • ACK Confirmation
  • Group Chat
  • Chinese Compatible

Station Recognition

Identifies FMO stations (by APFMO path and comment field), and highlights fellow APRSlocus users. All 37 symbol tables and 3571 standard icons are supported.

  • FMO Detection
  • Peer Marking
  • Official Icon Set

Packet & Log Viewer

Raw packets displayed in monospace with long-press copy. Parsed results sorted by type: position, message, weather, status. Built-in hierarchical logs for debugging.

  • Raw Packet View
  • Type Filtering
  • Debug Logs

Connectivity & Background

Auto-connects to APRS-IS public servers over TCP or WebSocket. Progressive reconnect: 8 → 16 → 32 → 60 seconds. Android uses a foreground service to stay online.

  • Auto Reconnect
  • Foreground Service
  • System Notifications

Auto Updates

In-app update checker with two channels (GitHub / GitCode). Platform-aware download routing and historical version access.

  • Dual Channels
  • Platform Routing
  • Historical Versions

Personalization

Chinese / English UI, dark mode, custom accent colors, scalable UI (85%–130%). Six-step onboarding wizard on first launch.

  • Multi-language
  • Dark Mode
  • OOBE Wizard

Frequently Asked Questions

From Passcode to battery drain — everything we could think of.

Can't receive / send messages?

Most likely an unverified Passcode. Entering -1 only lets you connect — it won't work for messaging. Visit APRS Passcode Generator to generate your own Passcode and enter it in Connection Settings. If the server returns unverified, a yellow banner appears at the top of the home page — tap "Go to Settings" to fix it.

How do I set up a Passcode?

In step 6 of the wizard or under Settings → Connection, use your full callsign (including SSID suffix, e.g. BG7LZQ-3) to generate a Passcode, then paste it in.

Connection fails / keeps dropping?

The app has built-in progressive reconnect (8 → 16 → 32 → 60 seconds). If it persists, check your network, make sure the server address (default rotate.aprs2.net:14580) and port aren't blocked, or try a different server in Connection Settings.

Can't see nearby stations on mobile?

Check if your target country/region is selected in the Receive Filter, and verify that the receive range (lat/lon + radius) covers your location. By default, only Chinese (B-prefix) stations are received.

Does background positioning drain the battery?

Android uses a foreground service for continuous positioning. You can adjust the report interval in Location / Beacon settings, or switch to manual reporting to reduce power usage. The notification bar has a one-tap "Exit" button.

Map display issues on Windows?

AMap JS mode falls back to AMap tiles on Windows to avoid WebView2 compatibility issues. You can also switch to Vector Map (no API key needed, best compatibility) in Display → Map Type.

Signature conflict / version downgrade on install?

Since v1.5.2, Android builds use the official release signature. CI and local builds use the same key — just install over the old version. If upgrading from a much older build, uninstall and reinstall.
